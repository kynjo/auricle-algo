# Auricle v111 — типизированные Mutators и алгоритмические исправления

## Установка

Это патч, а не самостоятельный дистрибутив. Установить **поверх версии с
`auricle_v111_relations_harmony_fix.zip`**, которая уже включает предыдущие
исправления ритма и музыкального времени.

Закройте Auricle. Распакуйте архив в каталог с `auricle_gui.py`, заменяя файлы
и сохраняя вложенные каталоги. Новый модуль `mutators.py` обязателен.
Настройки, assets и остальные неизменённые файлы в архив не включены.

## Mutators: типы и единицы

| Цель | Данные | Доступные операции |
| --- | --- | --- |
| rhythm | Только 0/1: пауза/удар | Rotate, Reverse, Invert, Stretch, Compress, Probability, Mutate, Shuffle, Mirror |
| pitch | Относительные полутоны; 0 — полноценная тоника | Rotate, Reverse, Invert, Transpose, Stretch, Compress, Mutate, Shuffle, Mirror, Humanize, Octave, Scale |
| velocity | 0–1 | Rotate, Reverse, Invert, Stretch, Compress, Probability, Mutate, Shuffle, Mirror, Humanize, Threshold, Scale |
| timing | Gate 0–1,5, до множителя Role Duration | Те же операции, что для velocity |

Timing меняет длительность ноты. Настройки Swing/Humanize в секции временных
параметров отдельно управляют моментами начала нот.

- Список в строке Mutation зависит от выбранной цели. При смене цели
  несовместимый тип заменяется на Rotate в той же строке, с поддержкой Undo/Redo.
- Сохранённые несовместимые комбинации видны с пояснением, но обходятся движком.
  Автоматически переписывать их при открытии проекта не нужно.
- У Drum Kit и Drum Voice нет новой цели pitch: аппаратная нота задаётся
  параметром MIDI Note голоса. Регулятор Mutation Pitch для Drum скрыт;
  ранее сохранённые pitch-строки видны как неактивные.
- Полутоны больше не прибавляются к маске ритма или velocity. Все допустимые
  операции возвращают значения в единицах своей цели.
- Новым ритмическим ударам назначаются velocity и gate до мутаций динамики.
  Нули, явно созданные мутациями velocity/timing, действительно заглушают
  событие и не восстанавливаются последующей подстановкой стандартного gate.
- Humanize учитывает pitch 0 как ноту; нулевые velocity/gate сохраняются.

## Два разных Amount

Верхние **Mutation Amount: Pitch / Rhythm / Velocity / Timing** задают силу
смешивания результата с исходным материалом. При 0 влияние отключено. Они
больше не умножают параметр внутри операции: уменьшение силы не сдвигает
нейтральные Transpose/Octave в отрицательную транспозицию. Для ритма смешивание
вероятностное: результат остаётся бинарным.

**Amount в строке** сохраняет смысл конкретной операции:

| Операция | Смысл Amount |
| --- | --- |
| Transpose | −12…+12 полутонов; 0,5 нейтрально |
| Octave | −2…+2 октавы; 0,5 нейтрально |
| Scale | Множитель 0,25…1,75; 0,5 = ×1. Это не квантование к гамме |
| Probability | Вероятность сохранения: 0 заглушает, 1 сохраняет всё |
| Threshold | Порог в диапазоне цели: 0…1 для velocity, 0…1,5 для gate |
| Mutate | Вероятность переключения удара/паузы либо небольшого изменения значения |
| Humanize | Глубина отклонения в единицах выбранной цели |
| Rotate | Сдвиг влево на долю длины окна; 1 — полный оборот |
| Stretch / Compress | Коэффициент 1…4, при сохранении общей длины окна |
| Shuffle | Число случайных перестановок; 0 — обход |
| Mirror | Длина зеркалируемой начальной части; 1 — симметрия всей фразы, 0 — обход |
| Reverse / Invert | 0 — обход, положительное значение включает операцию; силу задаёт верхний Mutation Amount |

Нейтральные и несовместимые строки не расходуют случайные числа и не
переключают LIVE на другой путь генерации.

## Последовательности и LIVE

- Mirror теперь создаёт симметричную последовательность, а не просто
  разворачивает левый фрагмент. Поддержаны чётные и нечётные длины.
- Compress повторяет укороченный мотив вместо удержания его последней ноты.
- Rotate, Reverse, Mirror, Shuffle, Invert и другие операции, которым нужны
  соседние значения, в LIVE обрабатывают целое окно вместе с паузами.
  Ритмические операции также могут создать удар на бывшей паузе.
- Для обычного блока окно соответствует Length, для активного мотива — его
  длине, для согласованного Drum Kit — плану. Обработанный материал кэшируется;
  изменение параметров, тональности, цепочки или переход к новому окну
  обновляет кэш. STOP/PLAY сбрасывает состояние.
- Окно свободного LIVE-генератора представляет последовательность попыток
  событий; само по себе добавление Mutator не переводит интервалы в сетку SEQ.
  Активные мотивы и согласованный Kit сохраняют собственную музыкальную сетку.

## Остальные замечания алгоритмического аудита

- **Fibonacci Rhythm:** Density покрывает весь диапазон, включая 0 ударов
  и заполнение всех шагов. Количество равно `floor(length × density)`.
  Позиции по остаткам Фибоначчи дополняются порядком на основе золотого
  сечения, если период не покрывает все клетки. Рост Density только добавляет
  удары; Offset переносит рисунок без изменения их количества.
- **Groove:** восьмые «и» учитываются вместе со слабыми шестнадцатыми.
  Accent усредняется только по звучащим шагам; значения на паузах не влияют
  на результат. Syncopation остаётся мерой активности между долями на
  шестнадцатой сетке, а не полноценным анализом метрического напряжения.
- **Динамика groove:** удалено скрытое первое масштабирование velocity.
  Единственная стадия плавно смешивается регулятором Groove Follow с
  исходным сигналом. При Follow 0 или отсутствии готового Drum source
  velocity и duration не меняются. Отдельный Groove Accent по-прежнему
  переносит акценты источника Drum→Bass.
- Справка и подсказки обновлены. Новый модуль включён в конфигурацию сборки.

Предыдущий патч уже устранил порядок вычисления Relations, ритмический
Amount, семантику Copy/Mix/Follow/Trigger/Quantize To, дубли циклов,
преждевременную публикацию отброшенных LIVE-событий, скачок Harmonic Strength
и схлопывание аккордов. Исправления Euclidean, Swing и окон Director входят
в предшествующий патч ритма и сохранены.
