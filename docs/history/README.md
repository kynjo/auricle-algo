# История разработки

Сюда перенесены прежние отчёты, описания патчей и их контрольные манифесты.
Они сохранены без изменения содержимого и отражают состояние проекта на момент
соответствующего патча. Их результаты проверок и контрольные суммы не описывают
текущую сборку.

- `CHANGES_*.md` — прежние тематические изменения.
- `CODE_AUDIT_V111.md`, `INTERACTION_AUDIT_2026-10-23.md` — архивные аудиты.
- `COMPOSITION_PLANNER_PATCH_RU.md` — описание отдельного патча Composition.
- `manifests/` — исходные JSON-манифесты патчей.

Актуальная справка: [HELP_RU.md](../HELP_RU.md).
Текущая уборка проекта: [CLEANUP_RU.md](../CLEANUP_RU.md).

`examples/example_full_project.json` — прежний пример с типом блока `PERCUSSION`.
Текущая версия его не загружает; исходный JSON сохранён для истории.
Рабочие демо находятся в корневом каталоге `examples/`.
