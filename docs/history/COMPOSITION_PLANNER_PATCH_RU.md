# Auricle v2.0 — Composition Planner patch

Эта поставка добавляет отдельную вкладку **COMPOSITION** в Auricle v2.0. Номер версии не меняется.

## Установка

1. Закройте Auricle.
2. Распакуйте содержимое архива поверх чистого `Auricle-v2.0-source.zip`, соглашаясь на замену файлов.
3. Если используете Python-окружение, запускайте приложение из обновлённой папки; новые модули `composition_planner.py` и `composition_planner_ui.py` должны лежать рядом с `auricle_gui.py`.
4. Для frozen-сборки пересоберите приложение по `docs/BUILDING.md`; старый EXE/AppImage не получит новую вкладку простым копированием Python-файлов.
5. Откройте `examples/composition_planner_demo.json` или создайте собственную форму. Planner выключен по умолчанию; включите `Enable composition`, когда будете готовы применить секционные настройки к MIDI.

## Содержимое

В архиве только изменённые и новые файлы: UI, runtime, модель/сохранение, транспорт, гармонизация, тесты, документация и демопроект.

## Проверка

153 целевые проверки Composition / Harmony / Transport прошли. Из-за отсутствия PySide6 в среде подготовки Qt offscreen UI-тесты не запускались; они добавлены в `tests/test_composition_planner_ui.py` и выполнятся в окружении разработки с установленным PySide6.
