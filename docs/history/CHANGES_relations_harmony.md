# Auricle v111 — Relations и гармонизация

## Установка

Этот патч рассчитан на актуальную версию с предыдущим исправлением ритма
`auricle_v111_rhythm_time_fix.zip`. Закройте Auricle и распакуйте архив в папку
с `auricle_gui.py`, сохраняя структуру каталогов и заменяя одноимённые файлы.
В архиве только изменённые и новые файлы. Зависимости устанавливать заново не нужно.

## Relations

Расчёт вынесен в `relation_runtime.py`. Цепочки следуют графу потоков, а не
порядку строк. Изменение rhythm учитывается перед зависимыми velocity, duration,
density и accent; изменение velocity — перед производным accent. Проверка циклов
учитывает эти зависимости, не сообщает ложный цикл только из-за встречных
связей между разными потоками и не дублирует один цикл в разных поворотах.

Встроенные Drum→Bass и Chord→Melody формируют исходное состояние. Явная связь
между соответствующими потоками заменяет встроенное преобразование. После
этого рассчитывается граф пользовательских Relations.

| Операция | Новое поведение |
| --- | --- |
| Copy | Заменяет выбранную долю событий значениями источника. Amount задаёт долю замены; при 1 — полное копирование. |
| Mix | Плавно смешивает числовые значения. Для rhythm добавляет выбранные удары источника, сохраняя собственные. |
| Follow | Для pitch приближает к ближайшему классу высоты источника с учётом Base Note. Для остальных числовых потоков управляет огибающей; для rhythm прореживает собственные удары по активности источника. |
| Quantize To | Привязывает значения назначения к набору значений источника. Pitch использует ближайший класс высоты, rhythm в SEQ переносит собственные удары к ближайшим ударам источника; в LIVE пропускает совпадающую активность. |
| Modulate | Добавляет влияние источника, ограничивая результат диапазоном назначения. Для rhythm добавляет выбранные удары. |
| Trigger | Преобразует положительную активность источника в единичный сигнал; Amount регулирует влияние на назначение. |

Amount = 0 и Probability = 0 нейтральны. Curve преобразует Amount до применения
операции. Ритм остаётся бинарным; малый Amount больше не включает сразу весь
рисунок. Выбор событий воспроизводим и не меняется при перестановке строк.
Pitch сохраняет гамму и размещается в регистре назначения, поэтому Copy из
низкого Bass в Melody может переносить ноту по октавам.

При нескольких входах в один поток используются нормированные веса целей.
Затем суммируется Modulate и применяются множители Follow. Для rhythm отдельно
объединяются добавляющие и прореживающие влияния. Поэтому перестановка строк
не выбирает случайного «последнего победителя».

Числовые потоки имеют свои диапазоны: velocity/density/accent — 0…1, duration —
0…1,5 значения Gate, pitch — допустимые MIDI-ноты с учётом регистра и гаммы.
При связи разных измерений используется нормированное преобразование единиц.
Нулевая velocity больше не превращается в едва слышимый Note On с velocity 1.

### Задержка и обратная связь

В SEQ Delay читает предыдущие позиции циклического источника. Для рёбер внутри
цикла графа задержка составляет минимум один шаг; начало рассчитываемого
буфера не заимствует ещё не вычисленные значения его конца.

В LIVE Delay читает предыдущие опубликованные попытки генерации, включая паузы.
Общий Drum Kit сохраняет предыдущий снимок до обновления группы голосов.
Циклическая связь использует предыдущий зафиксированный кадр событий транспорта.
Обновление UI и повторный расчёт в кадре не продвигают обратную связь; кадры без
новой активности также не увеличивают её глубину.

LIVE-событие, отклонённое Fill/Density, больше не публикуется как удар и не
ставит Parameter Modulation в очередь. Точкой чтения Relations и Parameter
Modulation остаётся выход генерации; Mute и Event Probability транспорта
по-прежнему относятся к последующей отправке MIDI.

## Гармоническое влияние

- Harmonic Strength / Plan anchor теперь плавно меняет долю привязанных нот.
  Значение 0 оставляет исходные ноты, 1 привязывает все. Сильные доли и каденции
  повышают вероятность, но больше не обходят регулятор при значении 0,01.
- Метрические акценты различаются для 2/4, 3/4, 4/4, 5/4, 6/8, 7/8 и 12/8.
  В 6/8, например, вторичная опора приходится на 1,5 четвертной доли.
- Решение определяется Seed, блоком и музыкальной позицией. Повторная проверка
  того же события не перебрасывает случайный выбор.
- Встроенный Chord→Melody также выбирает опорные события постепенно и учитывает
  разные Base Note источника и назначения.

## Размещение аккордов

Обычный генератор аккордов и Harmonic Plan используют один алгоритм размещения.
Учитываются Role Center и Width. Если выбранная раскладка помещается в регистр,
сохраняются её интервалы и инверсия. Если Spread слишком велик, голоса складываются
по октавам с сохранением классов высоты и их порядка. Отдельные ноты больше не
обрезаются до одной границы регистра.

Если Width физически недостаточен для всех голосов, выбирается минимально
необходимый выход за его границы. Ноты сохраняются внутри MIDI 0…127, голоса не
сливаются. Исправлен также случай повторяющихся классов высоты при инверсии в
малых гаммах, включая Whole Tone.

## Проверка

Полный регрессионный прогон: 1046 тестов прошли. После уточнения квантования
в обратных связях и хранения опубликованных LIVE-событий финальный целевой
прогон завершился успешно: 511 тестов.
Проверены порядок строк и блоков, несколько входов, циклы и задержки, LIVE-паузы,
общий Drum Kit, плавность Strength, разные размеры, крайние MIDI-регистры,
длинные прогрессии, UI, Undo/Redo и включение нового модуля в сборку.

MIDI проверялся через программный приёмник сообщений; физическое MIDI-оборудование
в этой проверке не использовалось. Тесты прежнего дробного rhythm, velocity выше 1
и обязательной привязки сильных долей при неполном Strength обновлены под новые
музыкальные правила.
