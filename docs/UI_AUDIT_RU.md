## Иконки и запуск

В assets добавлены исходные DRUM.svg, BASS.svg, MELODY.svg, PAD.svg и CHORD.svg из UI-base. Для BASS взята последняя версия из Auricle_BASS_SVG_PNG.zip. Сами SVG не перерисовывались; цвет для темы применяется при отображении. Значки есть в Blocks, выборе типа, меню типов, Perform и карточках инструментов Composition. Рендеринг иконок кэшируется, ресурсы включены в wheel и существующую схему сборки приложения.

Стартовый размер — до 1440 × 900 px, ограничен рабочей областью текущего экрана с запасом под оконную рамку. Окно центрируется на выбранном мониторе. Проверены также небольшие рабочие области и мониторы с отрицательными координатами.

## Отзывчивость

- Карточки Blocks обновляются на месте; одинаковые обновления не создают повторные обработчики.
- Ручки Drum Kit, параметры Process и Amount мутации не пересоздают Inspector при каждом движении. Изменение типа и структуры продолжает перестраивать нужные редакторы.
- При переходе к другому инструменту сохраняется один экземпляр редактора Drum Kit. Смена проекта и состава голосов проверяется по идентичности модели.
- Убрана отправка событий конструирования виджетов в фильтр истории; повторные запросы пересчёта геометрии объединяются одним таймером.
- Завершение жеста колеса использует один перезапускаемый таймер. Закрытые контекстные меню удаляются.
- Фоновая визуализация пропускает занятые блокировки транспорта и состояния вместо ожидания в GUI-потоке. MIDI-обратная связь после применения значения сохранена.

Контрольный замер: Qt offscreen, 1366 × 850, 15 последовательных пересборок Inspector с профилированием. Среднее время: **165.7 → 84.6 мс**, снижение примерно **49%**. В повторяющихся циклах число живых Qt-объектов возвращается к тем же значениям для соответствующего выбранного инструмента; роста между циклами не обнаружено. Сохранённый редактор Kit увеличивает число скрытых виджетов у мелодических инструментов, позволяя не строить его заново при возвращении.

## Подключение и проверка

- 770 проверок передачи значений контролов в модель для 22 генераторов: числовые параметры, флажки, списки и текстовые поля.
- Отдельно проверены специфические параметры BASS, MELODY, PAD, CHORD и Drum Voice в режиме LIVE.
- Проверены числовые поля, списки и флажки всех девяти типов Process; проверено сохранение контролов при непрерывной правке Process и Amount мутации.
- Проверены размеры в десяти темах, отсутствие обрезания карточек инструментов, адаптивная сетка и размеры стартового окна.
- **167 профильных тестов пройдены**; набор включает MIDI Learn, значения и стрелки ручек, очередь транспорта, автоматические влияния и сохранение работоспособности интерфейса при занятых блокировках.
- Wheel собран без загрузки зависимостей; наличие новых модулей и SVG проверено. Приложение успешно запущено из распакованного wheel вне каталога исходников в режиме smoke test.

В сравнительном полном прогоне обнаружены **130 сбоев, общих для исходной версии и ветки UI**. Сбой ожидания занятой блокировки GUI устранён. Пять старых проверок прежних подписей, индивидуальной ширины кнопки и минимального размера растровых ресурсов обновлены для нового интерфейса и SVG и отдельно проверены. Общие остаточные сбои перечислены в UI_AUDIT_KNOWN_TEST_FAILURES.txt; они не объявлены исправленными этим UI-патчем.
