<a name="quickstart"></a>

## Быстрый старт

1. Выберите MIDI-выход к синтезатору, сэмплеру или DAW. Auricle генерирует MIDI, а звук создаёт принимающий инструмент.
2. Добавьте DRUM или тональный блок. Настройте канал, ноту/корень, алгоритм и плотность. Главный Play прослушивает Blocks.
3. Редактируйте источник в Generator, затем Structure, Timing, Musical и Mutation. Process Layers преобразуют потоки; Relations связывают инструменты.
4. В Composition добавьте секции, задайте такты, переопределения макросов и Active/Density/Velocity инструментов. Запустите Composition Play.
5. Сохраните проект. Undo/Redo охватывает аранжировку и параметры; Panic отпускает зависшие ноты.

| Параметр | Описание |
| --- | --- |
| **BPM** | Темп в четвертных нотах в минуту, общий для Blocks, Composition, исполнения и MIDI Expression. |
| **LENGTH** | Длина исходного буфера последовательности в шагах; независима от длительностей секций в тактах. |
| **KEY** | Общий корень материала, основанного на гамме. Явные тоники Harmonic Plan независимы. |
| **SCALE** | Общая гамма материала; блоки могут иметь собственные настройки гаммы. |
| **SEED** | Зерно проекта для повторяемой генерации. Regenerate перестраивает материал, но не запускает воспроизведение. |

Единицы: одна доля — четверть; обычный базовый шаг — 0.25 доли (шестнадцатая). MIDI-каналы — 1–16, ноты и значения контроллеров — 0–127. Ноль означает паузу в ритме/Pattern, но может быть полноценной корневой ступенью высотного генератора.

<a name="composition"></a>

## Composition · форма и аранжировка

Composition распределяет музыкальные настройки по секциям на общем с Blocks транспорте. Обзор формы остаётся видимым; SECTION, INSTRUMENTS и GLOBAL редактируют разные уровни. Выбор секции меняет только редактор. Главный Play прослушивает Blocks без секционной автоматизации и Perform; Composition Play запускает подготовленную форму.

| Параметр | Описание |
| --- | --- |
| **Enable composition** | Подготавливает форму без запуска. Composition Play включает и запускает план; главный Play прослушивает Blocks. |
| **Meter** | Общий размер формы. Доля — четверть: 4/4 = 4 доли, 6/8 = 3, 7/8 = 3.5. |
| **Play composition** | Запускает Composition с позиции From, используя настройки и назначения секций на общем транспорте. |
| **Stop composition** | Останавливает Composition и отпускает её ноты. Главный Stop/Space останавливает воспроизведение глобально. |
| **From** | Selected section — с редактируемой секции; Form start — с начала формы; Timeline cursor — с сохранённой позиции таймлайна. |
| **End** | Loop form повторяет форму; Stop at end отпускает ноты на её конце; Hold last section продолжает с финальными настройками и концами кривых. |
| **Sections** | Выбор открывает редактирование и не перематывает воспроизведение. Перетаскивайте карточки или используйте стрелки для смены порядка. |
| **Timeline** | Щёлкните или перетащите и отпустите для перемотки с шагом шестнадцатой. При воспроизведении Blocks задаёт будущий курсор Composition. |
| **TOTAL** | Суммарная длина секций в тактах, четвертных долях и времени при текущем BPM. LENGTH в заголовке — шаги исходного буфера, а не длина формы. |
| **New section type** | Стартовый пресет новой секции. Тип не ограничивает дальнейшее редактирование. |
| **+ Section** | Добавляет секцию выбранного типа; максимум 128 секций. |
| **Duplicate** | Копирует выбранную секцию вместе с макросами, кривыми, настройками и назначениями инструментов. |
| **Move earlier** | Перемещает выбранную секцию раньше в порядке воспроизведения. |
| **Move later** | Перемещает выбранную секцию позже в порядке воспроизведения. |
| **Remove** | Удаляет выбранную секцию из формы; Undo восстанавливает изменение. |
| **Controlled parameters** | Показывает музыкальные параметры, на которые может влиять Composition. |

<a name="composition-section"></a>

### SECTION · имя и время

| Параметр | Описание |
| --- | --- |
| **Name** | Имя выбранной секции на карточке и таймлайне. |
| **Type** | Смысловая метка секции. Её смена сохраняет настройки; Apply type preset заменяет их стартовыми значениями. |
| **Duration** | Длина выбранной секции, 1–128 тактов размера Composition. |
| **Blend in** | Входное смешивание макросов в тактах, не длиннее секции; включает стык повтора. Плавно интерполирует финальные макросы предыдущей секции. Не является аудиокроссфейдом и не смешивает все коэффициенты инструментов. |
| **Color** | Цвет отображения секции; на музыку не влияет. |
| **Apply type preset** | Заменяет настройки макросов и блоков выбранной секции стартовыми значениями её типа. |

Intro, Verse, Build, Drop, Break, Bridge, Transition и Outro дают стартовые настройки. Одну 8-тактовую Main можно использовать как простой цикл. Реальное время определяют Duration секции и Meter Composition. LENGTH в заголовке меняет исходный материал, а не форму.

<a name="composition-macros"></a>

### SECTION · макросы и кривые

| Параметр | Описание |
| --- | --- |
| **Energy** | Общая динамическая энергия. В Composition влияет на velocity относительно текущей основы Global; 0.5 — нейтральный центр. |
| **Tension** | Повышенная напряжённость ослабляет привязку к аккордовым тонам у BASS/MELODY, следующих Harmonic Plan. |
| **Density** | Формирование общей или секционной плотности. Ноль не гарантирует тишину; для неё задайте Density инструмента = 0 или отключите Active. |
| **Variation** | Интенсивность динамических/акцентных вариаций. Независима от Seed генератора. |

| Параметр | Описание |
| --- | --- |
| **Override** | Выключено — следование текущему Global с игнорированием значения и кривой секции. Включено — действует макрос секции. |
| **Value** | Значение макроса секции, 0–100%; используется при включённом Override и выключенном Curve. |
| **Curve** | Использует редактируемую кривую вместо постоянного значения; Override тоже должен быть включён. |
| **Shape** | Smooth плавно соединяет точки без выбросов; Linear даёт прямые отрезки; Step удерживает значение до следующей точки. |
| **Curve editor** | X — время от начала до конца секции; Y — 0–100%. Двойной щелчок добавляет точку, перетаскивание перемещает; правый щелчок/Delete удаляет внутреннюю точку. Крайние точки сохраняются. |

Override выключен → текущий Global. Override включён, Curve выключен → постоянное значение секции. Оба включены → кривая секции. Blend in интерполирует финальные макросы предыдущей секции во входящие значения, включая стык повтора. Первый запуск формы начинается с её собственных начальных значений. Blend in действует на макросы: секции не перекрываются и все локальные коэффициенты инструментов не затухают автоматически.

<a name="composition-phrase"></a>

### SECTION · Phrase

| Параметр | Описание |
| --- | --- |
| **Phrase** | Многоэтапная исполнительская фраза секции; None сохраняет действие макросов и коэффициентов. Запускается с Composition. |
| **Amount** | Сила фразы секции, 0–100%. |
| **Fit to section** | Пропорционально растягивает этапы фразы на длину секции и удерживает финальное состояние на её конце. |
| **Duration** | Длительность фразы в четвертных долях при выключенном Fit; после завершения фраза плавно освобождает свой исполнительский слой. |
| **Targets** | All включает текущие и будущие блоки; выбранный список ограничивает цели. Пустой список не выбирает никого. Локальный Technique имеет приоритет. |

Фраза состоит из этапов; превью этапов показывает назначенные приёмы. Fit пропорционально распределяет этапы по секции. Без Fit фраза заканчивается по Duration и плавно освобождает свой слой. Локальный приём инструмента без Fit ведёт себя иначе: его конец удерживается до завершения секции. При смене секции и перемотке восстанавливаются соответствующие секционные назначения.

<a name="composition-instruments"></a>

### INSTRUMENTS · локальные настройки

| Параметр | Описание |
| --- | --- |
| **Active** | Разрешает ноты только в этой секции. Глобальный Mute по-прежнему отключает инструмент. Карточка Kit меняет все его голоса. |
| **Active** | Разрешает выбранному блоку или голосу выдавать ноты в этой секции. |
| **Technique** | Inherit phrase использует назначение фразы секции; None исключает инструмент из него; именованный приём заменяет его локально. Коэффициенты продолжают действовать. |
| **Amount** | Сила явно выбранного приёма инструмента, 0–100%. |
| **Shape** | In плавно входит в изменение; Out быстро меняется и замедляется; Out–in–out сглаживает оба края; In–pulse нарастает и возвращается. |
| **Fit** | Растягивает приём на секцию. Выключено — используется Beats, затем конечное состояние удерживается до конца секции. |
| **Beats** | Длительность локального приёма в четвертных долях при выключенном Fit. |
| **Gate** | Секционный множитель длительности ноты: 1 нейтрален. |
| **Density** | Вероятность сохранения события: 0 — тишина, 1 — все допустимые исходные события. Следующие секции могут вернуть события из источника. |
| **Velocity** | Секционный множитель velocity: 1 нейтрален, 0 — тишина, выше 1 — усиление динамики. |
| **Register Center** | Секционное смещение ручного Center блока в полутонах: 0 следует блоку, +12 поднимает регистр на октаву. Ноты Drum Voice фиксированы. |
| **Variation** | Детерминированная вариативность velocity событий секции; 0 выключает её. |
| **Accent** | Дополнительная сила акцентов секции; 0 нейтрален. |
| **Octave spread** | Дополнительная вариативность октавного размещения тональных нот; 0 нейтрален. Недоступно Drum Voice. |
| **Harmony** | Множитель привязки BASS/MELODY к аккордовым тонам Harmonic Plan; 1 нейтрален. |
| **Mode** | Глобальный режим SEQ/LIVE инструмента, общий для всех секций. |
| **Mute** | Глобальный Mute во всех секциях, независимо от локального Active. |
| **Details / Voices** | Открывает подробные настройки блока и отдельных Drum Voice. |
| **Preview** | Превью назначенного исполнительского приёма; выбор приёма не запускает отдельное прослушивание. |

| Параметр | Описание |
| --- | --- |
| **Block / Drum Voice settings** | Открывает коэффициенты, Expression и MIDI-автоматизацию отдельных блоков/голосов. Карточка Kit изменяет все его голоса. |
| **MIDI override** | Выключено — наследуется MIDI Expression блока или родительского Kit; включено — действуют секционные CC, Pitch Bend и Aftertouch выбранного инструмента/голоса. |

Active и коэффициенты принадлежат выбранной секции; Mode и Mute глобальны. Карточка DRUM изменяет все его голоса; Details/Voices позволяет различить отдельные голоса. Density = 0 или выключенный Active отключает инструмент в секции. Register Center смещает ручной центр до финального размещения по гамме/гармонии, сохраняя классы высоты октавным размещением; фиксированные ноты ударных не перестраиваются.

<a name="composition-global"></a>

### GLOBAL · общие музыкальные настройки

Musical Director и Harmonic Plan действуют на весь проект. Выбор другой секции не делает их локальными. Manual performance audition открывает отдельный Perform и запускается только явным действием прослушивания. Для воспроизводимой аранжировки используйте секционные Phrase/Technique.

<a name="composition-example"></a>

### Пример · восьмитактовое нарастание

Добавьте Build, задайте Duration = 8 тактов и Meter = 4/4 (32 четвертные доли). Включите Energy Override + Curve: начало низкое, конец высокий. Density Override оставьте выключенным для следования Global. Бас оставьте Active, а мелодию отключите в предыдущей секции. Назначьте фразу или локальный приём с Fit. Запустите From = Selected section, затем выберите Loop form для прослушивания стыка. Исходные блоки можно сравнить главным Play.

<a name="blocks"></a>

## Blocks · музыкальные роли

<a name="block-drum"></a>

### DRUM

Набор независимых Drum Voice. У каждого голоса свои источник, обработка, MIDI-нота и маршрут. Согласованный режим размещает ролевые голоса на общей сетке; Free оставляет голос независимым.

<a name="block-bass"></a>

### BASS

Низкая опора композиции. Groove Follow/Accent связывают партию с ударными; Harmonic Plan привязывает её к аккордовым тонам. Register Center/Width ограничивают размещение по регистру.

<a name="block-melody"></a>

### MELODY

Тональная мелодическая линия с гаммой, регистром и необязательной привязкой к аккордовому источнику или Harmonic Plan. Умеренная плотность помогает сохранить читаемый контур.

<a name="block-pad"></a>

### PAD

Протяжённая гармоническая фактура. Gate, Role Duration и Sustain задают длительность; Chord Size/Spread/Inversion формируют локальные созвучия, либо Harmonic Plan задаёт явные аккорды.

<a name="block-chord"></a>

### CHORD

Ритмическая аккордовая партия. Генератор задаёт активность, а настройки аккорда или Harmonic Plan — созвучие. Gate разделяет короткие удары и связные аккорды.

| Параметр | Описание |
| --- | --- |
| **Name** | Имя инструмента или голоса; не меняет MIDI-маршрут. |
| **Type** | Музыкальная роль: DRUM, BASS, MELODY, PAD или CHORD. Определяет обработку партии и доступные настройки. |
| **Algorithm** | Исходный генератор. Его настройки находятся в Generator; следующие слои обрабатывают полученный материал. |
| **Mode · SEQ / LIVE** | SEQ повторяет сгенерированный буфер; LIVE создаёт события при воспроизведении. Согласованные ударные в обоих режимах используют общую сетку шестнадцатых. |
| **Mute** | Глобальное отключение инструмента или голоса во всех секциях Composition. |
| **MIDI channel** | Выходной канал 1–16. Drum Voice может наследовать канал набора. |
| **MIDI note** | Базовая MIDI-нота. У Drum Voice выбирает звук на принимающем драм-инструменте. |
| **Output port** | MIDI-выход. Наследуемый маршрут Drum Voice следует выходу родительского набора. |

<a name="parameters"></a>

## Параметры блоков · общие слои

Показываются параметры, применимые к выбранному блоку/голосу. В проекте могут сосуществовать прежние поля: явная Pattern Density имеет приоритет над Role Density. Перетаскивание/колесо кноба меняет ручное значение; двойной щелчок возвращает значение по умолчанию; контекстное меню содержит MIDI Learn и управление влияниями, где это поддерживается.

<a name="parameters-0"></a>

### Structure / Density

| Параметр | Описание |
| --- | --- |
| **Pattern Density** | Доля сохраняемых событий генератора до последующих исполнительских слоёв: 0 убирает исходные события, 1 сохраняет все. |
| **Event Probability** | Вероятность воспроизведения допустимого события при каждом проходе. |
| **Anchors** | Вероятность сохранения опорных, структурно важных событий. |
| **Support** | Вероятность сохранения поддерживающих событий между опорами. |
| **Ornaments** | Вероятность сохранения декоративных событий. |
| **Length** | Число исходных шагов, используемых слоем Structure в пределах буфера проекта. |
| **Rotation** | Циклический сдвиг структурного рисунка в шагах. |
| **Role Density** | Запасная плотность роли, если Pattern Density не задана явно. Явная Pattern Density имеет приоритет. |

<a name="parameters-1"></a>

### Timing

| Параметр | Описание |
| --- | --- |
| **Rate** | Множитель скорости шагов: 2 удваивает скорость обычной сетки. Согласованный Kit и активный мотив используют собственный шаг. |
| **Swing** | Задерживает чередующиеся шаги до половины шага; BPM не меняется. |
| **Humanize** | Случайное отклонение начала события, в долях шага. |
| **Offset** | Сдвиг начала события в долях шага; знак задаёт направление. |
| **Gate** | Длительность ноты относительно шага. 1 заполняет шаг; значения выше 1 допускают перекрытие. |
| **Live Gate** | Настройка длительности LIVE-событий; взаимодействует с длительностью роли и исполнительскими слоями. |
| **Live Min** | Минимальный интервал между свободными LIVE-событиями в четвертных долях. |
| **Live Max** | Максимальный свободный LIVE-интервал в четвертных долях. Циклическая сетка, мотив или Kit могут задавать время отдельно. |
| **Role Duration** | Множитель длительности на уровне роли; сочетается с Gate. |
| **Pad Sustain** | Коэффициент длительности протяжённых нот PAD. |

<a name="parameters-2"></a>

### Pitch / Register / Harmony

| Параметр | Описание |
| --- | --- |
| **Root** | Корневая MIDI-нота для отображения материала в гамму этого блока. |
| **Scale** | Гамма для отображения ступеней генератора. Явные аккорды Harmonic Plan имеют собственные тоники и типы. |
| **Transpose** | Ручное смещение высоты в полутонах; независимо от Register Center. |
| **Octave** | Ручное смещение в октавах, по 12 полутонов. |
| **Pitch Range** | Диапазон отображения материала генератора в ноты, в полутонах. |

| **Register Width** | Ширина регистрового окна роли в полутонах. |

| **Chord Spread** | Разнос голосов аккорда в полутонах. |
| **Inversion** | Переносит голоса аккорда между октавами для изменения обращения. |
| **Follow Harmonic Plan** | Разрешает тональному блоку следовать текущему аккорду Harmonic Plan. Ноты DRUM не меняются. |
| **Harmonic Strength** | Сила притяжения к аккордовым тонам у BASS/MELODY, следующих Harmonic Plan. |
| **Voice Smooth** | Уменьшает большие скачки высоты и голосоведения между гармоническими событиями. |

<a name="generators"></a>

## Генераторы · все параметры источников

<a name="generator-0"></a>

### Euclidean

Ритм Евклида распределяет заданное число ударов максимально равномерно по циклу. Используйте Steps, Pulses и Rotation, чтобы менять рисунок акцентов, не меняя общую плотность.

| Параметр | Описание |
| --- | --- |
| **Steps** | Длина евклидова цикла в шагах. |
| **Pulses** | Число ударов, распределяемых по циклу; не превышает его фактическую длину. |
| **Rotation** | Циклический сдвиг евклидовых ударов в шагах. |

<a name="generator-1"></a>

### Bresenham

Bresenham рассматривает ритм как дискретную растеризацию линии. Подходит для чётких механических распределений событий по циклу.

| Параметр | Описание |
| --- | --- |
| **Steps** | Длина ритмического цикла Брезенхэма в шагах. |
| **Pulses** | Число ударов, распределяемых алгоритмом дискретной линии. |
| **Rotation** | Циклический сдвиг ритма Брезенхэма. |

<a name="generator-2"></a>

### Polyrhythm

Polyrhythm объединяет два независимых цикла. Cycle A и Cycle B создают интерференционные рисунки, общий период которых может быть длиннее каждого исходного цикла.

| Параметр | Описание |
| --- | --- |
| **Cycle A** | Период цепочки импульсов A в шагах. |
| **Cycle B** | Период цепочки импульсов B в шагах. |
| **Phase A** | Сдвиг цепочки импульсов A в шагах. |
| **Phase B** | Сдвиг цепочки импульсов B в шагах. |
| **Combine** | OR оставляет события любой цепочки; AND — совпадения; XOR — события только одной из цепочек. |

<a name="generator-3"></a>

### Thue-Morse

Thue-Morse создаёт рекурсивно организованный бинарный рисунок. Он даёт повторение с контролируемым самоподобием и хорошо подходит для необычной ритмической симметрии.

| Параметр | Описание |
| --- | --- |
| **Rotation** | Сдвиг двоичной последовательности Туэ—Морса в шагах. |
| **Invert** | Меняет активные и неактивные клетки местами до обработки плотности. |
| **Density** | Доля сохраняемых ударов последовательности Туэ—Морса. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-4"></a>

### Fibonacci Rhythm

Density задаёт число ударов во всём диапазоне 0–1, от тишины до заполнения всех шагов. Fibonacci Rhythm строит расположение событий на основе структуры Фибоначчи. Density и Offset определяют, насколько явно последовательность проявляется в ритме.

| Параметр | Описание |
| --- | --- |
| **Density** | Плотность от 0 (тишина) до 1 (все шаги) с размещением по структуре Фибоначчи. |
| **Offset** | Сдвигает ритм Фибоначчи в шагах. |

<a name="generator-5"></a>

### Fibonacci

Fibonacci создаёт детерминированную числовую последовательность, которую можно отображать на высоту или другие музыкальные измерения. Range, Stride и Offset формируют её музыкальное поведение.

| Параметр | Описание |
| --- | --- |
| **Degree span** | Сворачивает числовую последовательность в указанное число ступеней гаммы. |
| **Stride** | Умножает значения последовательности до сворачивания в диапазон ступеней. |
| **Offset** | Добавляет смещение в ступенях до операции остатка. |
| **Reverse** | Разворачивает исходную последовательность. |

<a name="generator-6"></a>

### Recaman

Recamán создаёт нелинейную целочисленную последовательность с частыми сменами направления. Подходит для неровных мелодических контуров и развивающихся паттернов.

| Параметр | Описание |
| --- | --- |
| **Degree span** | Сворачивает числовую последовательность в указанное число ступеней гаммы. |
| **Stride** | Умножает значения последовательности до сворачивания в диапазон ступеней. |
| **Offset** | Добавляет смещение в ступенях до операции остатка. |
| **Reverse** | Разворачивает исходную последовательность. |

<a name="generator-7"></a>

### De Bruijn

Последовательности De Bruijn проходят комбинации символов с контролируемым покрытием. Они полезны для систематического разнообразия при минимуме непосредственных повторов.

| Параметр | Описание |
| --- | --- |
| **Order** | Длина двоичных комбинаций, систематически перебираемых последовательностью. |
| **Rotation** | Циклический сдвиг результата De Bruijn. |
| **Mode** | Rhythm использует клетки как удары/паузы; Pitch отображает последовательность в ноты. |

<a name="generator-8"></a>

### Markov

Markov выбирает следующее музыкальное событие по вероятностям переходов. Max Jump, Rest, Repeat, Leap и Seed управляют балансом стабильности и исследования.

| Параметр | Описание |
| --- | --- |
| **Max Jump** | Максимальное обычное перемещение по ступеням гаммы. |
| **Degree offset** | Смещение в ступенях гаммы, а не в полутонах. |
| **Octaves** | Дополнительный октавный разнос линии Маркова. |
| **Rest** | Вероятность паузы в последовательности Маркова. |
| **Leap** | Вероятность увеличенного высотного скачка. |
| **Repeat** | Вероятность повторить предыдущую ступень. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-9"></a>

### Random Walk

Random Walk перемещается по пространству высоты или значения небольшими ограниченными шагами. Drift, Return Bias и Range определяют, будет ли линия блуждать или оставаться около центра.

| Параметр | Описание |
| --- | --- |
| **Step** | Максимальное одиночное перемещение случайного блуждания в полутонах. |
| **Range** | Ограниченный размах блуждания в полутонах. |
| **Start** | Начальное высотное смещение блуждания в полутонах. |
| **Return Bias** | Сила возвращения к центру блуждания. |
| **Drift** | Направленный дрейф: отрицательный — вниз, положительный — вверх, 0 — баланс. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-10"></a>

### Interval Walker

Interval Walker выбирает движения по интервалам, а не абсолютным нотам. Step, Range, Leap Chance и Return Bias формируют мелодический контур.

| Параметр | Описание |
| --- | --- |
| **Step** | Базовый интервал перемещения в полутонах до необязательной квантизации в гамму. |
| **Return** | Склонность возвращаться к центру блуждания. |
| **Range** | Допустимый размах интервального блуждания в полутонах. |
| **Leap** | Вероятность увеличенного интервального скачка. |
| **Quantize** | Scale привязывает ход к выбранной гамме; Chromatic сохраняет хроматическое движение. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-11"></a>

### Scale Walker

Scale Walker перемещается по ступеням выбранной гаммы. Direction, Step, Leap Chance и Octave Range дают контролируемое мелодическое движение.

| Параметр | Описание |
| --- | --- |
| **Step** | Размер шага Scale Walker в ступенях гаммы. |
| **Direction** | Вероятность движения вверх: 0 — вниз, 1 — вверх, 0.5 — баланс направлений. |
| **Octaves** | Число октав, доступных Scale Walker. |
| **Leap** | Вероятность увеличенного скачка по гамме. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-12"></a>

### Weighted Scale

Weighted Scale назначает разные вероятности ступеням гаммы. Подходит для тональных мелодий с намеренным перевесом в сторону определённых нот.

| Параметр | Описание |
| --- | --- |
| **Weights** | Неотрицательные веса ступеней через запятую, например 4,1,2,1,3,1,1. Больший вес повышает частоту выбора. |
| **Octave spread** | Вероятность переноса выбранного тона в другую октаву. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-13"></a>

### Arpeggiator

Arpeggiator перебирает тоны аккорда или гаммы с заданными порядком, диапазоном октав и направлением. Подходит для гармонического движения и остинато.

| Параметр | Описание |
| --- | --- |
| **Pattern** | Индексы ступеней через запятую, например 0,2,4,6. Ноль здесь — корень, а не пауза. |
| **Octaves** | Число октав арпеджио. |
| **Direction** | Порядок обхода: вверх, вниз или вверх/вниз. |
| **Octave mode** | Cycle перебирает октавы по порядку; Random выбирает их с учётом Seed. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-14"></a>

### Probability

Probability делает события стохастическими по заданному порогу вероятности. Это простой способ превратить плотный источник в разреженный развивающийся поток.

| Параметр | Описание |
| --- | --- |
| **Probability** | Вероятность события на шаге генератора. |
| **Pitch Range** | Диапазон случайно выбираемых высотных смещений. |
| **Center** | Центр случайного распределения высоты. |
| **Octaves** | Дополнительная октавная вариативность случайных нот. |
| **Velocity Floor** | Минимальная относительная сила нажатия создаваемых событий. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-15"></a>

### Pattern

Pattern воспроизводит явно заданный пользователем числовой паттерн. Используйте его, когда алгоритмическая обработка должна работать вокруг известного ритмического или мелодического зерна.

| Параметр | Описание |
| --- | --- |
| **Pattern** | Амплитуды ритма через запятую: 1,0,0.5,0. Ноль — пауза; ненулевые значения задают силу события. |
| **Rotation** | Циклический сдвиг явного паттерна в шагах. |
| **Scale** | Умножает амплитуды явного паттерна. |
| **Probability** | Вероятность сохранения удара на уровне генератора Pattern. |
| **Reverse** | Разворачивает явный паттерн перед сдвигом. |
| **Step chance** | Вероятность каждого шага при воспроизведении, заново на каждом проходе после обработки. Следует Reverse/Rotation; All 100% сбрасывает все шаги. |

<a name="generator-16"></a>

### Cellular Automaton

Cellular Automaton развивает бинарную ленту по локальным элементарным правилам. Выберите граничные условия и выводите последнюю строку, след эволюции или XOR-сводку. В режиме Pitch неактивные клетки становятся паузами.

| Параметр | Описание |
| --- | --- |
| **Rule** | Номер правила элементарного клеточного автомата, 0–255. |
| **Generations** | Число итераций правила над Seed cells. |
| **Density** | Плотность сохранения активных клеток автомата. |
| **Mode** | Rhythm выдаёт удары; Pitch превращает активные клетки в ноты, неактивные — в паузы. |
| **Seed cells** | Начальная двоичная строка, например 00100000. Не совпадает с числовым зерном Seed. |
| **Boundary** | Wrap соединяет края; Fixed считает внешние клетки неактивными; Mirror отражает края. |
| **Evolution** | Final Row выводит последнее поколение; Evolution Trail — след поколений; XOR Trail — их XOR-сводку. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-17"></a>

### L-System

L-System расширяет аксиому по правилам переписывания. В режимах Turtle символы + и - перемещают ступень, а [ и ] сохраняют и восстанавливают позицию ветви.

| Параметр | Описание |
| --- | --- |
| **Axiom** | Начальная строка символов для переписывания L-System. |
| **Rule A** | Строка замены каждого A на каждой итерации. |
| **Rule B** | Строка замены каждого B на каждой итерации. |
| **Iterations** | Число проходов переписывания; длина развёртки ограничена генератором. |
| **Mode** | Pitch/Rhythm отображают символы напрямую. В Turtle знаки +/− меняют направление, скобки сохраняют/восстанавливают позицию ветви. |
| **Pitch map** | Значения ступеней для символов, через запятую. |

<a name="generator-18"></a>

### Logistic Chaos

Logistic Chaos использует логистическое отображение для детерминированных, но чувствительных траекторий. Chaos R, Initial X и Smooth управляют степенью нестабильности.

| Параметр | Описание |
| --- | --- |
| **R** | Коэффициент логистического отображения; значения около 4 дают более хаотичные траектории. |
| **X** | Начальное состояние логистического отображения между 0 и 1. |
| **Octaves** | Высотный диапазон хаотического отображения в октавах. |
| **Burn-in** | Число пропускаемых итераций до начала звучащей последовательности. |
| **Smooth** | Сглаживает резкие изменения отображённых значений. |
| **Quantize** | Scale отображает хаос в выбранную гамму; Chromatic использует хроматические ноты. |

<a name="generator-19"></a>

### Turing Machine

Небольшая машина состояний обрабатывает конечную бинарную ленту. Busy Beaver, Alternator и Growth используют разные правила переходов; Marbles создаёт события при столкновении движущихся частиц. Лента, плотность и циклические края формируют результат.

| Параметр | Описание |
| --- | --- |
| **Machine** | Правила машины состояний: Busy Beaver, Alternator, Growth или вариант Marbles с зерном. |
| **Mode** | Интерпретирует итоговую ленту как ритм или высоту. |
| **Tape** | Начальная двоичная лента, например 00010000. |
| **Density** | Плотность сохраняемого результата машины. |
| **Wrap tape** | Wrap соединяет края ленты; выключено — головка отражается у границы. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

<a name="generator-20"></a>

### Orbital Sequence

Две независимые периодические орбиты встречаются на общей сетке шагов. Длины циклов и фазовые смещения создают длинные интерференционные рисунки; A, B, OR, AND, XOR и Interlock задают характер взаимодействия.

| Параметр | Описание |
| --- | --- |
| **Cycle A** | Период орбитальной цепочки A в шагах. |
| **Cycle B** | Период орбитальной цепочки B в шагах. |
| **Phase A** | Знаковый фазовый сдвиг орбиты A в шагах. |
| **Phase B** | Знаковый фазовый сдвиг орбиты B в шагах. |
| **Combine** | A/B выбирают одну орбиту; OR/AND/XOR объединяют удары; Interlock разносит совпадения. |
| **Output** | Отображает орбитальную активность в ритм или высоту. |
| **Rotation** | Циклический сдвиг в шагах после объединения орбит. |

<a name="generator-21"></a>

### Geometry Collision

Частицы отражаются внутри прямоугольника, треугольника, шестиугольника или круга. Квантованные столкновения с границами превращаются в ритмические события или ноты ступеней гаммы. Количество частиц, скорость и число шагов симуляции управляют плотностью и сложностью.

| Параметр | Описание |
| --- | --- |
| **Shape** | Граница столкновений: прямоугольник, треугольник, шестиугольник или круг. |
| **Mode** | Столкновения превращаются в ритмические события или высотный материал. |
| **Particles** | Число моделируемых движущихся частиц. |
| **Speed** | Множитель скорости частиц; увеличение обычно даёт больше столкновений. |
| **Substeps** | Число шагов моделирования на музыкальный шаг; увеличение требует больше вычислений. |
| **Seed** | Зерно воспроизводимой случайности. Одинаковые настройки и Seed воссоздают одинаковый исходный материал. |

## Мутаторы

| Параметр | Описание |
| --- | --- |
| **Type** | Преобразование, применяемое по порядку стека; список зависит от цели. |
| **Target** | Rhythm — удар/пауза; Pitch — высотные смещения; Velocity — динамика; Timing — gate/длительность, а не сдвиг начала. |

| Параметр | Описание |
| --- | --- |
| **Rotate** | Циклический сдвиг влево на Amount × длину потока; 1 — полный оборот. |

Меню учитывает совместимость: Transpose/Octave — высота; Threshold — velocity/timing; Probability — rhythm/velocity/timing. <a name="processes"></a>

## Process Layers

Процессы читают и преобразуют музыкальные потоки после генератора и мутаторов; это не аудиоэффекты. Delay измеряется исходными шагами, не миллисекундами. Clock-операции меняют поток, сохраняя BPM. Порядок процессов влияет на результат.

| Параметр | Описание |
| --- | --- |
| **Type** | Операция над потоком; процессы выполняются по порядку после генератора и мутаторов. |
| **Target** | Читаемый или преобразуемый поток: rhythm, pitch, velocity, duration, density или accent. |
| **Amount** | Общая сила процесса; Depth/Mix могут определять фактическое смешивание выбранной операции. |

<a name="process-0"></a>

### Counter

Добавляет повторяющийся управляющий сигнал Ramp, Triangle или Sine. Подходит для циклических изменений pitch, density или velocity.

| Параметр | Описание |
| --- | --- |
| **Length** | Период волны Counter в исходных шагах. |
| **Step** | Множитель наклона/амплитуды Counter; отрицательное значение меняет направление. |
| **Offset** | Смещает сигнал Counter/Modulo перед применением. |
| **Center** | Опорный уровень сигнала; в Modulo Gate заменяет отвергнутые значения. |
| **Phase** | Сдвиг в шагах внутри волны или маски clock. |
| **Reset** | Counter сбрасывает позицию через указанное число исходных шагов; независимо от длины волны Length. |
| **Depth** | Сила создаваемого сигнала или маршрута модуляции параметра, 0–1. |
| **Waveform** | Форма Counter: пила Ramp, треугольник Triangle или синус Sine. |

<a name="process-1"></a>

### Modulo

Создаёт повторяющийся модульный управляющий рисунок. Режимы Add, Multiply и Gate задают способ воздействия.

| Параметр | Описание |
| --- | --- |
| **Modulus** | Число шагов повторяющейся пилы Modulo. |
| **Offset** | Смещает сигнал Counter/Modulo перед применением. |
| **Scale** | Знаковый множитель амплитуды пилы Modulo. |
| **Center** | Опорный уровень сигнала; в Modulo Gate заменяет отвергнутые значения. |
| **Threshold** | Порог сравнения; пропускаемые значения определяются оператором или режимом. |
| **Depth** | Сила создаваемого сигнала или маршрута модуляции параметра, 0–1. |
| **Mode** | Add прибавляет пилу; Multiply масштабирует вход; Gate сохраняет значения выше Threshold, заменяя остальные на Center. |

<a name="process-2"></a>

### Compare

Сравнивает каждое значение с порогом и смешивает true/false значения. Полезен для gate, accent и условных преобразований.

| Параметр | Описание |
| --- | --- |
| **Threshold** | Порог сравнения; пропускаемые значения определяются оператором или режимом. |
| **True value** | Выходное значение при истинном сравнении. |
| **False value** | Выходное значение при ложном сравнении. |
| **Equality tolerance** | Допуск сравнения ==; не создаёт защёлкивающегося состояния гистерезиса. |
| **Mix** | Смесь исходного и обработанного потока: 0 — исходный, 1 — обработанный. Некоторые режимы Replace/Gate обходят смешивание. |
| **Operator** | Числовое сравнение: >=, >, <, <= или ==. |
| **Invert** | Меняет местами истинный и ложный результаты Compare. |

<a name="process-3"></a>

### Clock Divide

Замедляет поток периодическим gate или удержанием. Полезен для медленных огибающих и ритмических делений.

| Параметр | Описание |
| --- | --- |
| **Factor** | Коэффициент clock-рисунка в исходных шагах; преобразует поток без изменения BPM проекта. |
| **Phase** | Сдвиг в шагах внутри волны или маски clock. |
| **Duty** | Активная доля цикла clock-маски, 0–1. |
| **Mode** | Gate обнуляет неактивные позиции; Hold повторяет предыдущий результат. Период маски — 2 × Factor шагов. |

<a name="process-4"></a>

### Clock Multiply

Повторяет или открывает источник с заданным коэффициентом clock. Каждое исходное значение повторяется на Factor шагах; BPM проекта не меняется.

| Параметр | Описание |
| --- | --- |
| **Factor** | Коэффициент clock-рисунка в исходных шагах; преобразует поток без изменения BPM проекта. |
| **Phase** | Сдвиг в шагах внутри волны или маски clock. |
| **Duty** | Активная доля цикла clock-маски, 0–1. |
| **Mode** | Повторяет каждое исходное значение на Factor шагах. Gate дополнительно применяет Duty; Hold сохраняет повторы. BPM не меняется. |

<a name="process-5"></a>

### Memory

Читает предыдущее значение и смешивает его с текущим. Delay и Feedback создают инерцию и сглаживание.

| Параметр | Описание |
| --- | --- |
| **Delay** | Расстояние до предыдущего значения потока в исходных шагах, а не миллисекундах. |
| **Feedback** | Вес предыдущих значений в Memory/Feedback; в Delay — вклад последовательных повторов. |
| **Mix** | Смесь исходного и обработанного потока: 0 — исходный, 1 — обработанный. Некоторые режимы Replace/Gate обходят смешивание. |
| **Initial** | Значение до появления достаточного числа предыдущих шагов. |
| **Mode** | Blend смешивает результат с оригиналом по Mix; Replace напрямую использует смесь памяти, заданную Feedback. |

<a name="process-6"></a>

### Delay

Добавляет задержанные копии потока. Repeats, Feedback и Decay управляют структурой, похожей на эхо.

| Параметр | Описание |
| --- | --- |
| **Delay** | Расстояние до предыдущего значения потока в исходных шагах, а не миллисекундах. |
| **Repeats** | Число задержанных вкладов, суммируемых Delay. |
| **Feedback** | Вес предыдущих значений в Memory/Feedback; в Delay — вклад последовательных повторов. |
| **Mix** | Смесь исходного и обработанного потока: 0 — исходный, 1 — обработанный. Некоторые режимы Replace/Gate обходят смешивание. |
| **Decay** | Затухание последовательных задержанных вкладов или обратной связи. |
| **Initial** | Значение до появления достаточного числа предыдущих шагов. |
| **Mode** | Echo смешивает исходные и задержанные значения; Replace выводит задержанные; Gate сохраняет оригинал при положительной сумме задержек. |

<a name="process-7"></a>

### Feedback

Возвращает обработанный выход обратно в процесс для итеративного развития. Для pitch и velocity рекомендуется ограничивать feedback.

| Параметр | Описание |
| --- | --- |
| **Feedback** | Вес предыдущих значений в Memory/Feedback; в Delay — вклад последовательных повторов. |
| **Iterations** | Число проходов Feedback по потоку. |
| **Decay** | Затухание последовательных задержанных вкладов или обратной связи. |
| **Mix** | Смесь исходного и обработанного потока: 0 — исходный, 1 — обработанный. Некоторые режимы Replace/Gate обходят смешивание. |
| **Bias** | Смещение, добавляемое к предыдущему результату Feedback перед смешиванием. |
| **Clamp** | Симметричное ограничение результата Feedback; 0 выключает дополнительный предел. |
| **Initial** | Значение до появления достаточного числа предыдущих шагов. |

<a name="process-8"></a>

### Parameter Modulation

Читает музыкальный поток как управляющий сигнал для реального числового параметра. Модуляция применяется с задержкой события, чтобы избежать рекурсивного feedback в одном проходе.

| Параметр | Описание |
| --- | --- |
| **Destination** | Блок, принимающий Parameter Modulation; (none) оставляет маршрут неподключённым. |
| **Parameter** | Числовой параметр блока назначения, принимающий отображённый исходный поток. |
| **Source min** | Входное значение, отображаемое в минимум назначения. |
| **Source max** | Входное значение, отображаемое в максимум назначения. |
| **Minimum** | Значение назначения при Source min; ограничено диапазоном целевого параметра. |
| **Maximum** | Значение назначения при Source max; ограничено диапазоном целевого параметра. |
| **Smoothing** | Сглаживает изменения модуляции параметра; большие значения дают более плавную реакцию. |
| **Depth** | Сила создаваемого сигнала или маршрута модуляции параметра, 0–1. |

<a name="relations"></a>

## Relations / Dialogue

| Параметр | Описание |
| --- | --- |
| **Source** | Блок, чей выбранный выходной поток читается. |
| **Destination** | Блок, принимающий эту связь. |
| **Output** | Исходный поток: rhythm, pitch, velocity, duration, density или accent. |
| **Input** | Поток назначения, изменяемый связью. |
| **Operation** | Copy заменяет, Mix смешивает, Quantize To выравнивает, Modulate изменяет значения, Follow следует контуру, Trigger управляет событиями, Dialogue чередует инструменты. |
| **Amount** | Сила влияния с учётом Curve. В Dialogue это Separation: 0 — обход, 1 — строгое чередование. |
| **Curve** | Преобразует Amount: Linear, Exponential, Logarithmic, порог Threshold или четырёхступенчатая Quantize. |
| **Delay** | Задержка в событиях источника (0, 1, 2, 4 или 8), а не в секундах. Циклическая обратная связь использует историю. |
| **Chance** | Вероятность применения связи. Dialogue проверяет её один раз на целый цикл вопроса/ответа. |
| **Enabled** | Включает связь или обходит её без удаления. |

<a name="dialogue"></a>

### Dialogue · вопрос и ответ

| Параметр | Описание |
| --- | --- |
| **Meter** | Размер такта для длительностей вопроса/ответа; независим от Composition. |
| **Call** | Длина реплики источника в тактах размера Dialogue. |
| **Response** | Длина реплики адресата в тактах размера Dialogue. |
| **Gap** | Тишина в четвертных долях после каждой реплики, включая границу повтора. |
| **Reply** | Own phrase сохраняет материал ответа; Echo следует контуру/акцентам вопроса; Contrast инвертирует их. Ритм ответа остаётся своим. CHORD/PAD/DRUM следуют только акцентам. |
| **Follow** | Сила влияния контура/акцентов вопроса на ответ; 0 сохраняет собственный материал. |

Цикл = Call + Gap + Response + Gap. Separation = 1 обеспечивает чередование; 0 обходит разделение. Cycle chance проверяется один раз на весь цикл. Нужны разные инструменты-владельцы: Drum Voice принадлежит своему Kit. Если инструмент входит в несколько пар Dialogue, приоритет у более ранней пары. Обычные Relations используют явные потоки; циклические графы читают задержанную историю без рекурсивного обновления в одном проходе.

<a name="performance"></a>

## Perform / Global

<a name="piano-roll"></a>

## Monitor / Piano roll

Горизонтальный масштаб задаёт Length (steps) независимо от исходного паттерна. Во время воспроизведения правый край — текущее время; старые события покидают фиксированное окно. При Stop и Freeze время окна останавливается. При 120 BPM 16 шагов занимают 2 секунды, 64 — 8 секунд. Без истории MIDI превью генератора использует ту же длину и обрезает шаги за её пределами. При выборе Drum Voice отображается этот голос, при выборе Kit — совокупная история голосов.

| Параметр | Описание |
| --- | --- |
| **Length (steps)** | Фиксированная длина видимого окна: 1–4096 шестнадцатых шагов. Один шаг — 0.25 четвертной доли. Меняет только отображение независимо от длины паттерна. Редкие ноты LIVE не растягивают масштаб. Значение сохраняется при переключении блоков и перезапуске программы. |
| **FREEZE** | Фиксирует историю нот, положение времени и масштаб темпа. Length остаётся доступным. Снимите галочку для просмотра текущей истории; Stop также останавливает движение временного окна. |

<a name="parameter-automation"></a>

## Composition · автоматизация параметров

AUTOMATION задаёт точные параметры блоков/голосов для выбранной секции. Правый щелчок по кнобу или подписи источника → Automate in Composition создаёт или открывает дорожку, сохраняет ручную основу и не меняет воспроизведение. Дорожки действуют при Composition Play; при Blocks/Perform и остановленном редактировании они не применяются. Зелёные точки показывают назначенные и действующие слои Composition.

| Параметр | Описание |
| --- | --- |
| **Add parameter** | Выберите инструмент/голос и параметр. Существующее назначение в выбранной секции откроется без дублирования. Назначение не запускает воспроизведение. |
| **Remove lane** | Удаляет выбранную дорожку; восстанавливаются ручная основа и остальные влияния. Undo возвращает назначение. |
| **Destination** | Блок или отдельный Drum Voice и точный параметр. Дорожки конкретного генератора ждут его включения; отсутствующие цели остаются видны для восстановления или Undo. |
| **Filter** | Поиск назначенных дорожек по инструменту, подписи или ключу параметра. Выбор инструмента фильтрует список и не изменяет назначения. |
| **Automation lanes** | Одно прямое назначение на параметр и секцию. Залитая зелёная точка означает влияние; контур — назначение или обход. Редактируется выбранная секция, воспроизведение может идти в другой. |
| **Value / Curve** | Value удерживает постоянную цель. Curve распределяет точки по длительности секции. Списки и текст используют снимки Value. |
| **Set / Add / Multiply** | Set задаёт абсолютную цель. Add и Multiply рассчитывают цель от последней ручной основы, а не предыдущего автоматического результата; накопления нет. |
| **Apply timing** | Auto выбирает музыкальную привязку для параметра. Continuous следует долям; 1/16, Beat, Bar, Source cycle и Section start удерживают значение между границами. Структурные значения не меняются непрерывно. Правка удерживаемой дорожки ждёт следующей границы; перемотка сразу восстанавливает значение позиции. |
| **Automation weight** | 0 обходит дорожку; 1 запрашивает полный вес Composition. Фактический вклад определяет общая политика параметра. Ненулевой вес списков/текста включает дискретный выбор по приоритету. |
| **Target value** | Точное значение в единицах параметра. Диапазоны и целочисленные/логические типы соблюдаются. Уже звучащие ноты сохраняют назначенное окончание. |
| **Parameter curve** | Двойной щелчок добавляет точку; перетаскивание перемещает; Delete/правый щелчок удаляет внутреннюю точку. Концы закреплены в начале/конце секции. Linear, Smooth и Step используют музыкальную позицию секции. |
| **Curve range** | График и поля точек используют общий диапазон и единицы параметра. Length ограничен текущей длиной проекта, Density — 0–1. Add задаёт прибавку, Multiply — безразмерный множитель. Допустимый поддиапазон сохраняется; фиксированные границы заблокированы. |
| **Exact point** | Время задаётся четвертными долями, значение — в единицах параметра. Для целых параметров значения округляются до целых; Multiply допускает дробные множители. Snap 1/16 привязывает время перетаскивания к 0.25 доли при любом размере. |
| **Full parameter range** | Восстановить полный текущий диапазон параметра без удаления точек кривой. Предел Length зависит от длины проекта. |
| **Ramp / Flat** | Ramp задаёт концам минимум и максимум диапазона кривой. Flat удерживает значение выбранной точки всю секцию. |
| **Shared influence policy** | Composition, Technique, Modulation/Relations и Macro используют общую политику параметра: Priority, Weighted blend или Manual only. Прямая автоматизация параметра и финальная обработка потока нот — разные стадии. |

Приоритет по умолчанию: Composition → Technique → Modulation → Macro; неполные веса пропускают нижние слои. Прежний порядок источников сохраняется под новой категорией Composition. Числа ограничиваются диапазоном и округляются после разрешения влияний. Списки/текст всегда выбираются по устойчивому приоритету, включая режим blend. Генерация SEQ объединяется на границах шестнадцатых; Source cycle фиксирует ручной цикл при входе в секцию. Stop/обход снимает автоматизацию и возвращает последнюю ручную основу. Вход в секцию, цикл формы и перемотка вычисляют музыкальную позицию без повторного исполнения прежних UI-правок.

<a name="troubleshooting"></a>

## Диагностика

- Нет звука: проверьте принимающий инструмент, MIDI-выход/канал/ноту, глобальный Mute, Active и Density секции, вероятность событий, очередь Dialogue и velocity. MIDI Monitor подтверждает исходящие сообщения.
- Секция не влияет: запускайте Composition Play; проверьте Enable composition и From. Выбор секции сам по себе не перематывает форму.
- Ползунок макроса не действует: проверьте Override, Curve, текущий Global и политику влияний. Включённая кривая заменяет постоянный ползунок.
- Обученная ручка реагирует поздно: при Pickup один раз пересеките ручное значение. MIDI IN → Diagnostics / Copy diagnostics показывает этапы входа, GUI, pickup, очереди и применения.
- Неожиданная высота: сравните Transpose в полутонах и смещение ступеней, Register Center, гамму и Harmonic Plan. Выбор ноты Drum Voice независим.
- Зависли ноты: используйте Panic/Stop и проверьте Sustain принимающего инструмента. При медленном UI отключите лишний поток монитора, уменьшите дорогой Geometry Substeps или избыточный стек обработки.
