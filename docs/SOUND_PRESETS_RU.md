# Пресеты алгоритмов и блоков

Кнопка **Presets…** находится в шапке Block Inspector. Окно открывается для выбранного блока или Drum Voice. Оно не запускает отдельное воспроизведение: результат слышен через текущий транспорт.

## Два уровня

| Уровень | Что загружается |
| --- | --- |
| Algorithm | Параметры выбранного алгоритма: числовые настройки, текстовые правила, переключатели, Variation Seed и шансы шагов Pattern. При выборе другого алгоритма меняется и генератор. |
| Block / Drum Voice | Алгоритм, музыкальные параметры, SEQ/LIVE, мутации, процессы и MIDI Expression. Для Drum Kit — также музыкальные настройки его голосов. |

Algorithm сохраняет музыкальные настройки блока: гамму, регистр, плотность, артикуляции и обработку. Block загружает сохранённую музыкальную основу целиком.

У пресета нет MIDI-портов, каналов, Base Note, имён, цветов, mute-состояния и идентификаторов сущностей. Они остаются у получателя. Не переносятся Relations, маршруты MIDI Learn, назначения Composition, политики влияний, выбранный мотив и фиксация его варианта. Существующие процессы Parameter Modulation и ссылки между Drum Voices сохраняются у получателя.

## Выбор и сравнение

В библиотеке есть заводские варианты для каждого алгоритма и для DRUM, BASS, MELODY, CHORD, PAD и отдельных Drum Voices. У каждого заводского варианта есть краткое описание. Фильтр алгоритма и поиск помогают сузить список.

Таблица показывает отличия от **ручной основы** выбранного блока. Для числовых параметров указываются единицы, если они заданы в общем каталоге. Значение `default` означает отсутствие явной настройки: используется стандартное значение движка. Длины, число импульсов и вращения ограничиваются длиной текущего проекта. Вложенные настройки голосов и цепочки обработки доступны в подсказках таблицы.

Нажмите **Apply** для загрузки. Изменение поступает в очередь транспорта; старые ноты и отложенные артикуляции выбранного инструмента завершаются. Другие инструменты продолжают работать. **Undo / Redo** отменяет и возвращает загрузку как обычное изменение проекта.

## Автоматизация

Пресет сохраняет ручные значения. Текущее отклонение кноба из-за Composition, макроса или модуляции не записывается как новая основа. При загрузке активные влияния и их подсветка продолжают действовать: параметр может оставаться под управлением автоматизации. Чтобы услышать исключительно ручную настройку, используйте существующую политику влияний параметра.

## Drum Kit

Пресет комплекта требует одинакового числа голосов каждой роли. Голоса сопоставляются по ролям, включая несколько голосов одной роли, а не по идентификаторам или MIDI-нотам. Порядок разных ролей может отличаться. Идентификаторы, имена, note map, каналы и маршруты существующих голосов сохраняются. Индивидуальный пресет Drum Voice сохраняет роль голоса-получателя.

Если состав комплекта не подходит, Apply недоступна. Пресет не удаляет и не создаёт голоса: существующие связи и секционные назначения остаются действительными.

## Пользовательская библиотека

**Save current…** сохраняет текущую ручную основу под указанным именем. Пресеты доступны между проектами и перезапусками программы. Повторное сохранение создаёт отдельную копию; оно не перезаписывает ранее сохранённый вариант.

**Export… / Import…** обмениваются отдельными JSON-файлами. Импорт создаёт новый пользовательский пресет. Проверяются формат, версия, алгоритм, структура и конечность чисел. Неисправные файлы не загружаются; при обнаружении в пользовательской библиотеке они остаются на диске. **Delete** удаляет только выбранный пользовательский пресет после подтверждения; заводские варианты доступны постоянно.

Пресет хранит настройки генерации, а не готовые ноты. Случайные алгоритмы продолжают учитывать общий Seed и идентификатор инструмента текущего проекта. Для повторения конкретного нотного материала используйте существующее сохранение в мотив.
