# v111 — Диалог между инструментами

## Установка

Архив `auricle_dialogue.zip` содержит только изменённые и новые файлы.
Он устанавливается поверх последней v111 с обновлением `auricle_update.zip`
и исправлением регистра `auricle_chord_fix.zip`.

Закройте Auricle, распакуйте архив в папку программы рядом с `auricle_gui.py`,
сохраняя подпапки и заменяя файлы, затем запустите программу.

## Как включить

1. Откройте **Relations → + Dialogue**. Строка появляется сразу, без отдельного окна.
2. В **Source** выберите инструмент, который задаёт вопрос, в **Destination** — отвечающий.
3. Оставьте **Separation = 1** для чёткого чередования. Нажмите PLAY.

Цветные участки под настройками обозначают вопрос и ответ, промежутки — паузы.
Во время PLAY по ним движется индикатор. Текст показывает текущую очередь и
оставшиеся доли. В карточках Perform появляются Calling / Responding / Waiting.

Операцию Dialogue можно также выбрать в обычной строке Relations. При этом
сохраняется её Amount, который здесь называется Separation. Для полного
чередования установите его в 1.

## Настройки

| Поле | Значение |
| --- | --- |
| Source / Destination | Кто задаёт вопрос и кто отвечает. Списки сохраняют цвета блоков. |
| Call · bars | Длина вопроса: 1–8 тактов. |
| Response · bars | Длина ответа: 1–8 тактов. |
| Meter | Размер такта диалога. Не меняет размер Drum Kit или Chord Plan. |
| Pause · beats | Пауза 0–4 четвертных доли после каждой реплики, включая конец цикла. |
| Reply | Own phrase, Echo или Contrast. |
| Follow · % | Сила заимствования контура и акцентов: 0 сохраняет собственный материал. |
| Separation | 1 — играет только текущий участник; 0 — обход диалога; между ними другой участник становится тише. |
| Cycle chance | Вероятность включить диалог на целый цикл. Пропущенный цикл оба инструмента играют самостоятельно. |
| Enabled | Включение/отключение связи. |

Числовые поля поддерживают ввод, кнопки −/+ и колесо мыши.

## Чем отличаются ответы

**Own phrase**: инструменты чередуются, каждый играет собственный материал.

**Echo**: ответ заимствует направление движения мелодии и расстановку акцентов
из текущего вопроса. Например, восходящий вопрос вызывает восходящий ответ.

**Contrast**: направление мелодии и динамические акценты инвертируются.
Восходящий вопрос может получить нисходящий ответ.

Ритм и моменты атак ответа во всех трёх вариантах задаёт его собственный
генератор или Motif. Это не MIDI-эхо: Dialogue не создаёт ноты в пустом паттерне.
При различной длине реплик контур вопроса растягивается на длину ответа.

Заимствование высоты применяется к MELODY/BASS, в регистре и гамме отвечающего
блока. Chord Plan затем уточняет опорные ноты по **текущему** аккорду ответа.
CHORD/PAD сохраняют своё гармоническое расположение и заимствуют акценты.
DRUM сохраняет MIDI-ноты voice'ов и также заимствует только акценты; от барабанного
вопроса мелодический ответ получает акценты без копирования номеров MIDI-нот.

## Воспроизведение и взаимодействие

- SEQ, LIVE и их сочетания используют общую позицию в долях. BPM меняет скорость,
  сохраняя очередь. Переключение режима не начинает диалог заново.
- У DRUM участвует весь Kit: очередь распространяется на все его voice'ы.
  Можно выбрать обычный DRUM без Kit; он работает как одиночный инструмент.
- В памяти остаётся только текущий вопрос, максимум один образец на шестнадцатую.
  Mute и отклонённые вероятностью события в вопрос не записываются. При пустом
  вопросе ответ использует собственный материал.
- Ноты ограничиваются границей реплики. Смена очереди освобождает ещё звучащие
  ноты при Separation = 1. Генераторы продолжают движение, пока их очередь закрыта.
- Обычные Process, Mutation, Relations и встроенные связи работают до диалога.
  Dialogue сам по себе не заменяет DRUM → BASS или CHORD → MELODY.
- Один блок участвует в одной включённой паре Dialogue. Несколько независимых
  пар разрешены. При пересечении действует первая строка, у последующей показана
  причина обхода. Отсутствующий блок или связь блока с собой также дают обход.
- Настройки сохраняются в проект и поддерживают Undo/Redo, копирование и удаление
  строк. Запись вопроса — временное состояние воспроизведения, в проект не входит.
- Статический Pattern preview показывает материал генератора. Фактические
  события после Dialogue видны в MIDI Monitor, piano roll и Output у Drum Kit.

## Демо

Откройте `examples/instrument_dialogue_demo.json`. В нём шесть блоков:
DRUM KIT, BASS FOUNDATION, CHORDS, PAD TEXTURE, QUESTION и RESPONSE.
QUESTION (SEQ, канал 3) и RESPONSE (LIVE, канал 6) обмениваются однотактовыми
репликами на фоне C–Am–F–G. Остальные инструменты поддерживают фон.

Назначьте MIDI-порты и звуки на внешнем синтезаторе. Для сравнения переключайте
Reply между Echo / Contrast / Own phrase, затем Follow между 0 и 100.
Для отчётливой паузы попробуйте Pause = 0.5: общий цикл станет длиннее,
и его границы начнут смещаться относительно четырёхтактового гармонического плана.

## Проверки

Проверяются MIDI-очереди и окончания нот, смешанные SEQ/LIVE, Drum Kit,
Motif, смена BPM, Mute, обходы, ограниченность памяти, контур/акценты,
текущая гармония, сохранение, Undo/Redo и UI при ширине 820 px.
MIDI проверяется перехватом сообщений без физического устройства.
