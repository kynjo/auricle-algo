# Этап 2: развитие мотивов

## Установка обновления

Этот архив содержит только новые и изменённые файлы относительно
`auricle_algorithmic_midi_v111_motif_stage1.zip`. Нужна установленная сборка
первого этапа. Закройте Auricle и скопируйте содержимое папки
`auricle_algorithmic_midi_v111` из архива в каталог программы, рядом с
`auricle_gui.py`, заменив совпадающие файлы. Новые зависимости не нужны.

## Быстрая проверка

Откройте `examples/motif_development_stage2.json`, назначьте MIDI Out и нажмите
PLAY. Мелодия меняется каждые четыре доли: тема, три варианта, возврат к теме.
Бас меняется вдвое реже. Для сравнения SEQ/LIVE выключите Developing theme LIVE
и включите Developing theme SEQ: они используют один мотив и канал 1.
Канал баса — 2, Drum Kit — 10.

В Inspector выбранного блока откройте **SOURCE → MOTIF**. Все настройки
работают и для отдельного Drum Voice; панель Drum Kit остаётся закреплённой.

| Регулятор / действие | Что делает |
| --- | --- |
| Develop: Off | Повторяет исходную тему без автоматического развития |
| Melodic | Меняет часть слабых нот на соседние ступени текущей гаммы; для DRUM меняет слабые акценты velocity |
| Rhythmic | Меняет часть слабых атак и пауз; добавленные ноты получают мягкую velocity |
| Combined | Совмещает мелодические изменения и ритмические варианты |
| Amount | Глубина развития от 0 до 1. При 0 всегда звучит тема |
| Every · cycles | Сколько полных циклов удерживать один вариант: 1–16 |
| Return · variants | Через сколько периодов возвращаться к теме: 2–16, с учётом периода самой темы |
| Capture | Создаёт и выбирает новую тему из материала текущего генератора |
| Save variant | Сохраняет текущий вариант как отдельную тему и выбирает её с Develop: Off |
| History / Recall | Выбор и удержание одного из восьми последних отличающихся вариантов |
| Hold | Удерживает текущий вариант; снятие флажка возвращает развитие по текущей позиции транспорта |

Например, Every = 2 и Return = 4 дают два цикла темы, затем по два цикла
трёх вариантов; с девятого цикла возвращается исходная тема. Цикл равен
числу позиций мотива × Step · beats, независимо от LENGTH проекта.

Во время PLAY режим, Amount, Every, Return, Hold и Recall применяются на
границе следующего цикла. До этого статус показывает `changes next cycle`.
Поле Step по-прежнему задаёт музыкальную длительность шага, как в первом этапе.
Изменение настроек развития не пересоздаёт Inspector.

## Как сохраняется узнаваемость

Каждый вариант строится от исходной темы. Предыдущий вариант не становится
новой основой, поэтому ошибки и отклонения не накапливаются. Защищены первая
и последняя атаки, исходные акценты velocity ≥ 0.85, а также позиции на каждой
второй доле относительно начала мотива — метрическая опора 4/4. Паузы на этих
метрических позициях также сохраняются.

Melodic меняет ограниченную долю остальных атак, максимум на две ступени
гаммы. Rhythmic меняет ограниченную долю остальных позиций. Amount увеличивает
число допускаемых изменений; для мелодии при значении от 0.75 также допускается
движение на две ступени. Очень короткая тема или тема из одних защищённых
позиций может остаться неизменной: статус показывает `Theme · protected positions`.

Один мотив с одинаковыми настройками, гаммой и seed проекта даёт одинаковые
исходные варианты в SEQ и LIVE. Mute, регенерация, смена BPM и задержки рабочего
потока не меняют выбор варианта. При новом PLAY музыкальный отсчёт начинается
с темы; сохранённый Hold продолжает удерживать свой вариант.

После выбора варианта действуют обычные мутации, процессы, связи, роль,
макросы и параметры Kit. Они могут дополнительно менять или подавлять ноты.
Защита опорных позиций относится к самому развитию мотива, а не ко всей
последующей обработке.

## Создание и сохранение

Capture берёт детерминированный предпросмотр генератора до мутаций, связей
и макросов. В LIVE это не запись последних MIDI-событий. Длина ограничена
текущими LENGTH/Structure Length (до 128 позиций), исходный Step — 0.25 / Rate.
Velocity темы берётся относительно нейтральной базы 0.72, без добавочного Accent;
действующие настройки динамики продолжают обрабатывать её при воспроизведении.

Для Capture и Save variant имена создаются автоматически; существующие темы
не перезаписываются. Новые темы, привязки, настройки развития и материал Hold
сохраняются в обычном файле проекта. История последних восьми вариантов живёт
в текущем сеансе; нужный вариант можно сохранить через Save variant либо Hold.
Смена Source снимает Hold и очищает историю этого блока.

Согласованные роли Kick/Snare/Hat и общие fill всего Drum Kit остаются следующим
этапом. В этой сборке каждый voice развивает собственный мотив независимо.
