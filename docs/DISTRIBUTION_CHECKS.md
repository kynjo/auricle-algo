# Проверка дистрибутива v2.0.1

- 71 runtime-модуль сохранён из последнего рабочего патча; изменена только версия. Сохранены piano roll, Ratchet/Flam/Strum, назначения Composition, темы, SVG artwork, справка и примеры.
- Удалены старые pytest-тесты, dev-зависимости, технические отчёты предыдущих итераций, кэши, логи и результаты сборок из выдаваемого исходного архива. Проверки состава, ресурсов и запуска оставлены в `packaging/`.
- Оба workflow прошли actionlint 1.7.12 без ошибок.
- Валидатор проверил все 71 runtime-модуль, 11 обязательных assets, корректность SVG и JSON-примеров. Версии runtime закреплены в requirements и metadata Python-пакета.
- Wheel и sdist собраны. Все runtime-модули wheel побайтово совпали с исходниками. Sdist включает `.github/workflows` и не содержит тестов, кэшей или логов.
- Wheel установлен в отдельное окружение и успешно запущен из каталога вне checkout; artwork разрешается из установленного пакета.
- Реальный Linux executable собран PyInstaller и прошёл запуск с offscreen Qt из временного каталога без PYTHONPATH исходников.
- Linux AppImage собран с закреплёнными tool/runtime и SHA256, успешно извлечён и запущен без FUSE в режиме проверки. Это проверка запуска/ресурсов в headless Linux, без физического MIDI-устройства.
- Проверены 13 сценариев механизма публикации с локальным mock GitHub CLI: новый релиз, продолжение черновика, повторный полный выпуск, ошибка загрузки, неверный удалённый digest, неполный опубликованный релиз, отсутствие файла, неверная SHA256, неверный тег, конфликт тега с коммитом и обычный CI ветки после существующего релиза. Реальных сетевых операций публикации в этих проверках нет.
- Windows/macOS здесь не запускались: нативная сборка и smoke-check каждой ОС предусмотрены на соответствующих GitHub runners. Удалённый workflow ещё не выполнялся; конкретный репозиторий не задан.

Новый Release становится публичным только после успешных сборок всех четырёх целей и проверки девяти вложений. Сертификаты Apple/Microsoft не предоставлены; состояние подписи описано в `BUILDING.md`.
