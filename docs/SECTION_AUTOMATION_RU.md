# Адресная автоматизация Composition

Вкладка **Composition → AUTOMATION** задаёт конкретные параметры отдельного
блока или Drum Voice для выбранной секции. Например: Gate мелодии 0,3,
постепенное увеличение плотности Kick или смена алгоритма баса на начале такта.
Дорожки действуют при воспроизведении Composition. Основной Play запускает
Blocks; назначение и выбор секции сами воспроизведение не запускают.

## Назначение

1. Выберите секцию в Composition.
2. Нажмите ПКМ на кнобе, подписи параметра или поддерживаемом списке/поле
   Inspector → **Automate in Composition…**. Откроется назначенная дорожка.
   Второй способ: AUTOMATION → **+ Parameter**, инструмент/голос и поиск.
3. Выберите **Value** или **Curve**, операцию, время применения и вес.

Одно назначение «инструмент + параметр» на секцию. Повторное назначение
открывает существующую строку. Поиск и фильтр скрывают строки без удаления.
Галочка On обходит строку; Remove удаляет её. Максимум — 128 дорожек на секцию,
до 64 точек на кривую. Копия секции получает независимую копию назначений.

Параметры других генераторов доступны заранее: можно назначить смену
Generator algorithm и параметры будущего алгоритма в одной секции.
Неподходящий текущему алгоритму параметр получает статус unavailable for
generator; отсутствующий инструмент — missing target. Назначение сохраняется
для исправления или удаления. Алгоритм кита с отдельными голосами меняется
через голоса; сам кит продолжает работать как общий координатор.

## Значение и влияние

| Operation | Цель дорожки | Пример при ручной базе 0,6 |
| --- | --- | --- |
| Set value | Указанное абсолютное значение | 0,2 → цель 0,2 |
| Add to manual | Актуальная ручная база + операнд | +0,1 → цель 0,7 |
| Multiply manual | Актуальная ручная база × операнд | ×0,5 → цель 0,3 |

Add и Multiply каждый раз вычисляются от ручной базы. Они не прибавляются
к результату предыдущего тика. Цель ограничивается диапазоном параметра;
целочисленные значения округляются. Ручная правка во время исполнения
обновляет базу, а действующее значение продолжает определяться политикой.

**Weight** — сила дорожки 0…1. Ноль обходит дорожку. Смена Operation выбирает
нейтральный операнд (Add 0, Multiply 1, Set — ручное значение), сбрасывает
диапазон и создаёт линейный подъём кривой. Учтите это при смене операции
после редактирования кривой.

Алгоритм, гамма, режимы генератора, источники Groove/Chord и текстовые
правила — снимки выбора: только Value и Set, без интерполяции строк или id.
Boolean-параметры переключаются по порогу 0,5 и разрешают только Set.
Поддерживаются основные параметры Structure, Timing, Musical, Representation,
Mutation Amount, Kit/Map, известные параметры всех генераторов, seed,
паттерны и текстовые правила. Поля отдельных Process, Mutator и Relation,
MIDI-порт/канал, имена и глобальный BPM в этот список не входят. Для CC,
Pitch Bend и Aftertouch остаётся редактор MIDI Expression.

## Музыкальное время

Все позиции измеряются в **четвертных долях от начала секции**, а не в
секундах. BPM меняет скорость прохождения кривой, сохраняя музыкальные
позиции. Размер определяет длину такта: 4/4 = 4 четверти, 6/8 = 3 четверти.
Точки кривой хранят относительную позицию: изменение длины секции растягивает
кривую вместе с ней.

| Apply | Когда читается новое значение |
| --- | --- |
| Auto | LIVE float — Continuous; SEQ float и обычный integer — 1/16; длины/seed/структурные параметры — Source cycle; алгоритм/гамма — Bar |
| Continuous | По музыкальному времени на тиках транспорта |
| 1/16 | С шагом 0,25 четверти от начала секции |
| Beat | С шагом в одну четверть |
| Bar | На границах тактов выбранного размера |
| Source cycle | На границах исходного цикла инструмента |
| Section start | Один раз при входе; удерживается начальная точка |

Source cycle фиксируется при входе в секцию из ручных Structure Length и
Timing Rate: `length × 0,25 / rate` четвертей. У согласованного Kit сетка
общая, поэтому используется `length × 0,25`. Автоматизация самой длины
или rate не сдвигает границу, на которой должна применяться эта же дорожка.
Это цикл исходного паттерна, а не длительность всей формы или MIDI-ноты.

Для структурных, текстовых, boolean-параметров и выбора разрешены Section
start, Bar и Source cycle. Integer не использует Continuous. Недопустимые
варианты выключены; загруженная несовместимая настройка использует безопасный
Auto-эквивалент. Значение между границами удерживается.

При входе в секцию и перемотке значение сразу восстанавливается для
целевой позиции, без проигрывания пропущенных промежуточных изменений.
Живая правка действующей дорожки с привязкой ждёт следующей границы;
статус показывает ожидание и позицию применения. Отключение/удаление
дорожки и остановка снимают её влияние сразу. Уже звучащие ноты сохраняют
назначенные Note Off; автоматизация влияет на последующие события.

Кривые LIVE читаются на тиках транспорта. Материал SEQ пересчитывается
общим пакетом не чаще одного раза за 1/16; Continuous не обещает звуковую
интерполяцию внутри одного SEQ-события. Смена алгоритма сбрасывает состояние
генератора только затронутого инструмента.

## Редактирование кривой

**Range** — диапазон операнда, показанный по вертикали в реальных единицах.
У Set это значения параметра, у Add — прибавка, у Multiply — множитель.
Границы совпадают с текущими границами Inspector: например, при длине проекта
16 шагов Length имеет диапазон **1–16 steps**, Rotation — **0–15 steps**, а
Density — **0–1**. Нижняя граница Length — 1: нулевая длина не поддерживается.
Для числа шагов, нот и других целых параметров числовой ввод и вертикальное
перетаскивание точек используют целые значения. У Multiply коэффициент остаётся
дробным и обозначается **×**; время точек всегда задаётся в четвертных долях.

Поля Range, Value, Point Value и график используют одни и те же границы.
Старые кривые с общим пределом 128 отображаются и исполняются в допустимом
диапазоне выбранного параметра; нормированные позиции точек сохраняются.
Допустимый пользовательский поддиапазон остаётся на месте. **Full** возвращает
полный текущий диапазон без удаления точек. После изменения длины проекта
пределы обновляются; при единственном допустимом значении диапазон заблокирован.

Ramp создаёт подъём минимум → максимум; Flat удерживает значение выбранной
точки. Linear — прямые сегменты, Smooth — плавные, Step — удержание
предыдущей точки до следующей.

Двойной щелчок добавляет точку, перетаскивание двигает её. Delete или ПКМ
удаляет внутреннюю точку; крайние точки сохраняются. Поля Point beat и Value
задают выбранную точку численно. Snap 1/16 привязывает горизонтальное
перетаскивание к 0,25 четверти. Числовой ввод позволяет задать позицию точнее.
Стрелки двигают выбранную точку, Shift увеличивает вертикальный шаг.

При воспроизведении линия показывает реальную позицию транспорта, маркер
по вертикали — удерживаемый с учётом Apply уровень кривой. Под графиком
видны Manual, Effective и Automation target; это разные величины при
частичном весе и совместных влияниях.

## Единые правила источников

Кнопка **Influences…** открывает общую политику конкретного параметра.
Composition участвует в том же resolver, что Macro, Technique и Modulation.
Порядок по умолчанию: **Composition → Technique → Modulation → Macro → Manual**.
В существующих проектах сохраняется относительный порядок прежних категорий.

- **Priority:** верхний источник с полным весом определяет значение;
  частичный вес пропускает результат нижних слоёв.
- **Weighted blend:** среднее целей категорий и ручной базы с их весами.
  Число маршрутов одной категории не увеличивает её общий вес.
- **Manual only:** автоматические цели видны, но действующее значение
  определяется ручной базой.

Вес дорожки умножается на вес категории Composition. При Priority и весе
дорожки 0,5 цель 0,2 поверх нижнего результата 0,8 даёт 0,5. При Weighted
blend и равных весах Manual 0,8, Technique 0,6 и Composition 0,2 результат
равен примерно 0,533. Для выбора/текста всегда выбирается категория с
наивысшим приоритетом и ненулевым весом, в том числе при Weighted blend.

Это политика **параметра генератора**. Секционные коэффициенты Instruments,
выходные преобразования Global Macros, Stream Relations, Process и Mutators
продолжают обрабатывать музыкальные события после генерации. Например,
Manual only для Velocity Base не отключает последующее умножение velocity
на Energy. Окно Influences явно показывает это различие.

## Подсветка и жизненный цикл

Сохраняются цвета существующих источников: Composition — зелёный, Perform —
фиолетовый, Relations — янтарный. Заполненный индикатор означает реальное
участие слоя в результате, контур — назначение без действующего вклада.
Подсказка раскрывает секцию, цель, ручное и действующее значения. Параметр
может иметь сразу несколько источников. Значения кнобов обновляются через
существующий механизм обратной связи без генерации из потока UI.

В другой секции прежняя дорожка снимается; при Loop форма вычисляется заново,
при Hold удерживается конечное значение, при Stop возвращается текущая
ручная база или оставшийся нижний слой. В JSON, Undo/Redo и восстановление
сессии записываются назначения и ручные значения; временная смена алгоритма
или значение в середине кривой не становятся новой ручной настройкой.

Редактор использует общий heartbeat и очередь команд транспорта. Частые
правки объединяются перед применением; сохранение и история предварительно
завершают отложенную правку. Скрытый редактор не опрашивает своё состояние.

## Пример: постепенное уплотнение Build

1. Создайте Build на 8 тактов 4/4. Назначьте Kick → Fill Density.
2. Curve, Set value, Range 0,25…1, Ramp, Linear, Apply Bar, Weight 1.
3. Назначьте MELODY → Gate: Value 0,35, Apply Bar.
4. В следующей секции Drop задайте Kick Fill Density 1 и Gate мелодии 0,8.
5. Включите Composition и нажмите его Play. Во время Build плотность
   меняется по тактам, Gate удерживается; при входе в Drop применятся его
   назначения. Stop восстановит ручные настройки обоих инструментов.
