# Управление влияниями параметров и техники Coordinated Kit

## Где настроить

Нажмите числовое значение под регулятором, вызовите его контекстное меню
или откройте **Edit → Parameter influences…**. Выберите параметр.

В окне показаны ручная база, действующее значение, активные источники,
их целевые значения, вес и статус. Настройки относятся к выбранному
параметру выбранного блока или Drum Voice.

## Три режима

| Режим | Поведение |
| --- | --- |
| Priority | Источники применяются в заданном порядке приоритетов. Слева — самый высокий. |
| Weighted blend | Действующее значение — взвешенное среднее ручной базы и целей Composition, Macro, Technique, Modulation. |
| Manual only | Автоматические воздействия на этот параметр обходятся. Их цели остаются видны в таблице. |

По умолчанию порядок: **Composition → Technique → Modulation → Macro → ручная база**.
Composition здесь — адресные дорожки вкладки AUTOMATION. У старых проектов
без таких дорожек звучание не меняется; существующий порядок трёх категорий сохраняется.
Без адресной автоматизации при полном весе Technique определяет значение во время исполнения;
после её остановки слышен актуальный Modulation или Macro, а не старый
снимок значения до запуска техники.

Пример без дорожки Composition: ручная база 0,2, Macro 0,4, Modulation 0,6 и Technique 0,8.

- Priority по умолчанию: 0,8.
- Priority с Macro на первом месте: 0,4.
- Weighted blend с четырьмя одинаковыми весами: 0,5.
- Manual only: 0,2.

Вес **0** отключает категорию, **1** даёт полное влияние. В Priority
промежуточный вес пропускает нижележащий результат: например, Technique
0,8 с весом 0,5 поверх Macro 0,4 даёт 0,6.

Несколько маршрутов одной категории сначала усредняются с учётом их
собственных весов. Число одинаковых макросов не увеличивает общий вес
категории. Amount/Depth маршрута формирует его цель до общего смешивания.
Порядок обновления источников не меняет итоговое значение.
Целочисленные параметры после смешивания округляются и ограничиваются
диапазоном своего регулятора.

**Modulation** здесь — Process Parameter Modulation. Stream Relations,
обычные Process, Mutators, роль инструмента и выходные преобразования
Global Macros/Director действуют на музыкальные события отдельно. Например,
Manual only для Velocity Base сохраняет его ручную базу, а Energy по-прежнему
масштабирует velocity готовых нот. Это показано в нижней части окна.

Строки с выбором алгоритма, гаммы или текстом не усредняются: в режимах
Priority и Weighted blend выбирается категория с наивысшим приоритетом и
ненулевым весом. Manual only сохраняет ручной выбор.

[Время и назначение адресных дорожек](SECTION_AUTOMATION_RU.md).

## Остановка и редактирование

- Изменение ручной базы сохраняется, даже если действующий параметр сейчас
  контролируется автоматическим источником. В таблице видны оба значения.
- Остановка, завершение или замена Technique снимает её слой.
- При завершении Phrase слой Technique плавно теряет вес. Macro и Modulation
  продолжают обновляться во время этого затухания.
- Удаление маршрута Macro возвращает нижележащий результат.
- Удаление Process Parameter Modulation или Depth 0 отключает его слой;
  ранее поставленные отложенные значения удалённого маршрута не возвращаются.
- Действующий маршрут Modulation удерживает последнюю полученную цель
  между событиями. Передача по-прежнему происходит не раньше следующего тика.
- Настройки политики сохраняются в JSON проекта, участвуют в Undo/Redo
  и восстановлении сессии. Сами временные слои в документ не записываются.

## Accelerando и Ritardando в Coordinated Kit

У согласованного Kit общий BPM и сетка. Ощущение ускорения и замедления
создаётся изменением числа дроблений между опорными ударами:

| Техника | Что меняется |
| --- | --- |
| Accelerando | Complexity 0,05 → 0,95; Toms 0,05 → 0,65 |
| Ritardando | Complexity 0,95 → 0,05; Toms 0,65 → 0,05 |
| Stringendo, когда используется во Phrase | Complexity 0,1 → 0,9 и Velocity Base 0,62 → 0,9 |
| Smorzando, когда используется во Phrase | Уменьшаются Complexity, Velocity Base и Fill/Density |

Кривые Perform показывают именно эти параметры. Amount и Shape управляют
их движением; Duration/Length задаёт длительность жеста в долях.

Опорные позиции плана Kick/Snare сохраняются. Окончательный выход
по-прежнему зависит от Mute, Density, вероятностей и последующей обработки.
Drum Voice сохраняет свою аппаратную MIDI-ноту и канал.

У независимого Kit Accelerando/Ritardando продолжают менять Timing Rate.
При переключении Coordinated во время жеста применяется соответствующая
логика, а переставшие действовать назначения техники снимаются.
