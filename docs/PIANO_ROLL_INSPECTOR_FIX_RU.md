# Piano roll и стабильность Drum Inspector

Дата: 01.11.2026. Основа — полный очищенный проект Auricle v2.0.

## Piano roll

- В Monitor добавлено поле **Length (steps)**: 1–4096 шестнадцатых шагов,
  по умолчанию 16. Длина окна независима от LENGTH паттерна и числа событий.
- 16 шагов при 120 BPM — 2 секунды, 64 — 8 секунд. Во время исполнения окно
  перемещается с фиксированным масштабом; редкие LIVE-события не растягивают его.
  Ноты вне окна отбрасываются при отображении.
- Превью генератора использует тот же масштаб. Шаги за пределами окна обрезаются.
- Выбранная длина хранится в настройках интерфейса между блоками и перезапусками;
  её изменение не меняет проект, паттерны и MIDI-транспорт и не пересоздаёт Inspector.
- Stop удерживает положение времени. Freeze сохраняет историю, временную опору
  и масштаб темпа, в том числе при пересоздании Inspector; Length остаётся доступным.
- При выборе Drum Voice отображается этот голос; при выборе Kit — общая история
  его голосов. Добавлены описания и подсказки RU/EN в общей справке.

## Вертикальные рывки

Причиной была обратная связь: расчёт высоты страницы менял диапазон вертикального
скроллбара, а `rangeChanged` снова запускал расчёт высоты. С раскрытым Kit цикл
не завершался. Дополнительная проверка воспроизводит это на исходном коде.

- Убрана подписка перерасчёта на `rangeChanged`. Изменение ширины viewport
  по-прежнему вызывает адаптацию через Resize, в том числе при появлении скроллбара.
- Запросы после раскрытия секций и Rhythm Settings объединяются одним таймером.
- На проверенных ширинах 900, 1100, 1366 и 1600 px исходный Kit вызывал
  35–44 повторных расчёта за 350 мс; после исправления — один завершающий расчёт.
  Геометрия и диапазон прокрутки стабилизируются.
- Kit остаётся частью общей прокручиваемой страницы, экземпляры контролов сохраняются.

## Проверки

Python 3.12.14, PySide6 6.12.0, Linux, `QT_QPA_PLATFORM=offscreen`.

| Проверка | Результат |
| --- | --- |
| Новые тесты фиксированного окна и стабильности компоновки | 16 passed |
| Заключительный набор UI, Help, Groove Map, piano roll и адаптации | 113 passed |
| Последний результат каждой проверки: полный прогон + повтор затронутых тестов | 2072 passed, 135 прежних failed |
| Новые неустранённые сбои относительно исходного архива | 0 |
| Синтаксис Python | 212 файлов без ошибок |
| Wheel и запуск установленного пакета вне исходников | Успешно, код выхода 0 |

Полный прогон дал 2069 passed и 138 failed.
Три дополнительных сбоя относились к лишней пустой строке экспортов Help и
старому тесту, требовавшему подписку `rangeChanged`. Экспорты синхронизированы,
проверка заменена на реальную проверку Resize и отсутствия обратной связи;
все три повторно прошли в заключительном наборе выше. Код приложения при этом
не менялся после полного прогона. Оставшиеся 135 ошибок присутствовали в исходном
архиве; их список находится в [CLEANUP_TEST_FAILURES.txt](CLEANUP_TEST_FAILURES.txt).

Изменения тем, все assets, демонстрационные и сохранённые проекты сохранены.
Нативный UI Windows/macOS в этой среде не запускался.
