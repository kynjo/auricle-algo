# Проверка Musical Drum Kit · v2.0 · 29 октября 2026

**Обновление:** этот отчёт относится к первоначальному Musical Drum Kit.
Последующие исправления UI/runtime и новый общий прогон описаны в
[UI_PERFORMANCE_FIX_RU.md](UI_PERFORMANCE_FIX_RU.md) и `UI_VALIDATION.json`.

## Результат

- **1865 тестов, 0 failures, 0 errors, 0 skipped.**
- 117 тестовых модулей запускались в отдельных процессах pytest.
- Из них 45 новых проверок карты, мотивов, связей, MIDI-выхода и Qt-интерфейса.
- Python 3.12.14, PySide6 / Qt 6.12.0, mido 1.3.3, python-rtmidi 1.5.8.
- Wheel `auricle-2.0.0-py3-none-any.whl` собирается; оба новых модуля входят в пакет.
- Все исходные файлы assets сохранены без изменений. Встроенный профиль algo_conf сохранён.

## Что проверено

- Карта создаёт согласованный kit из молчащих исходных генераторов в SEQ/LIVE,
  на всех поддерживаемых размерах. Все четыре угла карты дают разные рисунки.
- Half-time сохраняет свой backbeat. Density имеет вложенные наборы событий,
  сохраняет опоры раньше украшений и даёт тишину при нуле.
- Развитие мотива воспроизводится после перемотки и при чтении планов в другом
  порядке. Fill разрешается в Return; периодический Return восстанавливает тему.
- OR, Answer, дополнение пауз, AND, XOR и Copy проверены по логике событий.
  Взаимные маршруты не зависят от порядка voices/строк; неверные, выключенные,
  чужие и Free-источники пропускаются. Опоры и разделение hats/fills сохраняются.
- Нулевая динамика от Process/Mutators и нулевая плотность voice не оживляются.
  Сохраняются аппаратные MIDI-ноты и каналы; параметры voices не переписываются картой.
- Настройки сохраняются/загружаются; новые параметры доступны модуляции.
- Проверены реальными Qt-виджетами: Musical kit, редактирование и удаление
  цветных inline-связей, новые кнобы без пересоздания закреплённой панели,
  выбор voice и Undo/Redo.
- Дополнительно записан MIDI-выход на 256 общих шагах со смешанными SEQ/LIVE
  отдельно в Blocks и Composition: 242 и 236 note-on соответственно, без
  расхождений с рассчитанными планами. В обоих режимах проверена перемотка.
- Исправлено и покрыто тестами начало секции внутри буфера Kit: выход SEQ
  использует тот же план секции, из которого построен буфер. Каденции следуют
  фактическому концу секции, включая секцию короче фразы Kit.

## Границы проверки

Длительный монолитный запуск с сотнями пересозданий Qt-окон в этой среде
завершался нестабильными ошибками нативных объектов, включая аварийное завершение.
Поэтому итог выше получен полным повторным запуском **всех** тестовых модулей
в отдельных процессах. Причина общего нативного сбоя не установлена; результат
не означает, что монолитный Qt stress-прогон исправлен.

Графический интерфейс проверялся в offscreen-режиме Linux. Подключение к
физической драм-машине, звук, Windows/macOS и нативные исполняемые сборки
в этой среде не проверялись. MIDI-посылки проверены через записывающий порт.

## Повторение проверки

После установки зависимостей и pytest, из корня проекта:

```sh
for test in tests/test_*.py; do
    QT_QPA_PLATFORM=offscreen python -m pytest -q "$test" || exit $?
done
```

Проверка новых возможностей отдельно:

```sh
QT_QPA_PLATFORM=offscreen python -m pytest -q tests/test_drum_rhythm.py
QT_QPA_PLATFORM=offscreen python -m pytest -q tests/test_drum_rhythm_ui.py
```
