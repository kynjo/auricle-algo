# Проверка объединённого интерфейса · 2026-10-28

- Общий набор: 1820 уникальных тестов. Первый общий прогон: 1818 успешных,
  два ожидали старый порядок шести вкладок. Ожидания обновлены под пять вкладок;
  оба теста успешно прошли повторно вместе с затронутыми проверками.
- Повторная проверка затронутых частей: 92 успешных теста. После окончательной
  настройки адаптивной компоновки — ещё 58 успешных UI/transport-проверок.
- Новые поведенческие проверки: SEQ/LIVE; 2/4, 4/4, 6/8, 7/8; точная длина
  коротких и длинных фраз; вход после перемотки; цикл; явные техники/None;
  цели Director и Drum Voices; снятие слоёв; удержание конца без постоянной
  регенерации; сохранение данных и цветов; независимый основной Play.
- Проверен настоящий Qt-интерфейс: тёмная Midnight и светлая Solar, 1600×1280
  и 820×720. Две/одна колонка; графики 140×100 px; карточки не пересоздаются
  при обычном изменении ширины; поля не выходят за viewport.
- Проверены Undo/Redo, отдельные настройки Drum Voices, ручное прослушивание,
  сохранение длительности при переключении Fit и обновление длительности
  при изменении Meter/Duration.
- Скриншот в README получен из работающего приложения с новым демо.
- Assets сохранены без изменения байтов. Python-модули проверены компиляцией.

Проверки выполнялись без физического MIDI-инструмента. Полный ZIP содержит
исходники, assets, примеры, документацию, тесты и сценарии сборки; виртуальное
окружение, кэши, журналы и временные результаты проверок не включены.
