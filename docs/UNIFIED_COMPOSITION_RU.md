# Composition + Perform · Auricle v2.0

Объединённая вкладка **COMPOSITION** содержит форму, автоматизацию макросов,
фразу выбранной секции и настройки исполнения каждого инструмента. Отдельной
вкладки PERFORM больше нет. Версия программы остаётся **v2.0**.

## Порядок настройки

1. В BLOCKS настройте генераторы, алгоритмы и MIDI-выходы. Основной Play в
   заголовке запускает только Blocks — без автоматических фраз и формы.
2. В COMPOSITION добавьте секции. Цвета различаются по типу; Color позволяет
   выбрать свой. Дубликат получает новый цвет, сохраняя настройки исходника.
   Секции можно переставлять перетаскиванием или стрелками.
3. Выберите секцию для редактирования: Name, Type, Duration (такты), Blend in.
   Выбор секции не перематывает проигрывание. Ширина секции на полосе формы
   пропорциональна её длительности; короткие секции имеют минимальную ширину,
   длинная форма допускает горизонтальную прокрутку.
4. SECTION MACROS задаёт значения/кривые Energy, Tension, Density и Variation.
   Без Override параметр следует общему макросу в заголовке. Blend in плавно
   вводит значения из предыдущей секции, включая стык цикла.
5. В SECTION PERFORMANCE выберите Phrase, Amount и Targets. **None** оставляет
   секцию без фразы; макросы и коэффициенты инструментов продолжают действовать.
   **Fit to section** растягивает фразу на длительность секции с учётом Meter.
   Без Fit длительность задаётся в четвертных долях. Вручную заданное значение
   сохраняется при временном включении Fit.
6. В INSTRUMENT PERFORMANCE настройте каждый инструмент. Нажмите локальный
   Play в COMPOSITION, чтобы запустить форму с назначенными приёмами.

## Организация вкладки

Верхняя часть COMPOSITION остаётся общей: управление воспроизведением, размер,
список секций и таймлайн формы. Под ней рабочая область разделена на четыре страницы:

- **SECTION** — имя, тип, длительность и Blend in выбранной секции; макросы
  Energy, Tension, Density и Variation с кривыми; назначение Phrase и Targets.
- **INSTRUMENTS** — карточки исполнения инструментов и раскрываемые подробные
  настройки Block / Drum Voice.
- **GLOBAL** — общие для проекта Musical Director и Harmonic Plan, а также
  отдельное окно Manual performance audition.
- **AUTOMATION** — точные значения и кривые параметров выбранной секции,
  музыкальные границы применения и общая политика влияний. Назначение через
  ПКМ по кнобу или подписи. [Подробное руководство](SECTION_AUTOMATION_RU.md).

Выбор секции не меняет текущий режим воспроизведения и не перемещает курсор.
Переход на другую страницу не сбрасывает выбранную секцию или её настройки.
Команда Details для блока/Drum Kit автоматически открывает страницу INSTRUMENTS.

В демо `examples/unified_composition_demo.json` показаны шесть инструментов,
шесть цветных секций, кривые, фразы и независимые техники в Build. MIDI-выходы
пустые: выберите свои порты перед прослушиванием. Форма длится 32 такта / 128
четвертных долей, то есть 1:04 при 120 BPM.

## Карточки инструментов

| Поле | Действие |
| --- | --- |
| Active | Разрешает этому инструменту играть в выбранной секции |
| Technique → Inherit phrase | Использует приём текущей стадии фразы для роли инструмента |
| Technique → None | Отключает у инструмента технику фразы; влияние Musical Director на цели фразы сохраняется |
| Явно выбранная Technique | Заменяет технику фразы собственным приёмом на время секции |
| Amount / Shape | Сила и временная форма явно выбранного приёма |
| Fit / beats | Растягивает приём на секцию либо задаёт длительность в четвертных долях |
| Gate | Коэффициент длительности нот, 0.25–2 |
| Density | Доля сохраняемых событий, 0–1 |
| Velocity | Коэффициент динамики, 0–1.5 |
| Center | Смещение Register Center, −24…+24; только для инструментов с высотой тона |
| SEQ / LIVE, Mute | Общие настройки блока, действуют во всех секциях |
| Details / Voices | Открывает подробные параметры блока или отдельных Drum Voices |

График справа размером **140×100 px** показывает нормированные кривые реально
выбранной техники. При воспроизведении выбранной секции отображается движущийся
указатель. Если инструмент наследует фразу, график меняется вместе с её стадиями.
Без фразы и явного приёма отображается пустая сетка.

Для Drum Kit коэффициенты карточки изменяют все голоса за одно действие.
Индивидуальные значения можно задать через Voices; подсказка карточки сообщает,
если значения голосов различаются. MIDI-ноты и каналы остаются настройками Voices.

В Targets можно выбрать все инструменты (включая добавленные позже) или явный
список. Пустой явный список означает отсутствие целей фразы. Выбор целей
распространяется и на техники, и на музыкальные изменения Director. Явная
Technique в карточке работает независимо от списка целей фразы.

## Проигрывание и переходы

- Основной Play: прослушивание Blocks для начальной настройки сэта.
- Play внутри COMPOSITION: форма + назначенное секциям исполнение.
- From: выбранная секция, начало формы или курсор timeline.
- Timeline: перемотка формы; при прослушивании Blocks меняет будущую позицию
  Composition, не прерывая текущую настройку звука.
- End: Loop form / Stop at end / Hold last section.
- Верхний Stop или Space останавливает всё. Локальный Stop останавливает форму.

Фраза или приём включается при входе в секцию, в том числе после перемотки.
Пропущенные стадии и ноты не воспроизводятся заново. Фраза с Fit и явные приёмы
удерживают конечные значения до выхода из секции; это действует и в Hold last.
Фраза без Fit заканчивается по собственной длительности и выполняет обычный
плавный release. На границе нейтральной секции временные слои снимаются,
SEQ-материал обновляется. Смена техники сама по себе не посылает Note Off;
отключение инструмента и Stop освобождают его ноты по обычным правилам.

Секции и их настройки сохраняются в JSON, поддерживают Undo/Redo. Цветные точки
у параметров сохраняют смысл: фиолетовый Perform, зелёный Composition,
янтарный Relations. Все глобальные макросы остаются только в верхней панели.

## Общие музыкальные настройки и ручная проверка

Musical Director и Harmonic Plan находятся в сворачиваемых блоках внизу
COMPOSITION. Это настройки проекта, а не отдельной секции.

Кнопка **Manual performance audition…** открывает прежние ручные средства
запуска фразы/техники. Открытие окна не запускает транспорт. Явный Play Phrase
или Restart переводит форму в режим ручного исполнения. Закрытие окна
не останавливает уже начатое прослушивание; используйте Stop.

## Откат

Новая сборка — полный комплект исходников и assets. Для проверки распакуйте
его в отдельную папку. Не накладывайте его на старую установку: удалённые
файлы прежних версий могут остаться при копировании поверх.

Для отката используйте исходный полный архив, приложенный вместе с новой
сборкой. Для проектов, сохранённых в новом интерфейсе, старый интерфейс не
показывает назначения Section Performance; сохраните копии важных JSON.
